# Brief — 2026.08.02-PROVIDER-CONTRACT-LOCALE

Владелец требует сделать swissknifeman надёжным хабом, который автоматически
настраивает Claude Code и Codex в каждом проекте по конфигу самого проекта.
Подключение не должно физически копировать Python-рантайм или плагины в проекты:
канон остаётся в SKM, а провайдеры получают независимые адаптеры.

Нужно устранить все выявленные болячки: старые `.agents/skills`, local overrides,
сломанные ссылки, legacy bundle-проекции, provider trust и дрейф Claude/Codex.
Оба провайдера должны использовать свои сильные стороны и не перезаписывать
конфигурацию или состояние друг друга.

Нужно перевести канонические скиллы, плагины, комментарии, диагностику и
документацию разработки на компактный английский. Русский остаётся языком рендера:
требуется английский по умолчанию и независимый наследуемый выбор языка плана,
ответа и диагностик. При русском языке плана сам план и provider-rendered текст
должны быть русскими.

В план должны попасть все найденные проблемы и обязательная пофайловая инвентаризация
флота: нельзя снова назвать проекты проверенными без evidence для каждого.
