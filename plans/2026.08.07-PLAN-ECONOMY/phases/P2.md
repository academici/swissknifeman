# P2 — Перестроить носители плана

## Phase Context

Фаза реализует замороженный контракт в файлах: журнал решений уезжает в каталог односоставных записей с двусторонними связями замещения, фазовый файл становится тонким индексом, пункт получает свой файл и свою историю, терминальные фазы уходят с живого пути чтения. Завершением считается план этого репозитория, полностью живущий по новой раскладке.

> СКЕЛЕТ — не детализирован, разворачивается /task:plan-design 2026.08.07-PLAN-ECONOMY P2

> **Контракт фазы (contract-first).** Потребляет: замороженный контракт P1 · Производит: раскладку `decisions/` с генерируемыми индексами, `phases/Pn/Pn.md` + `Pn.m.md` + `Pn.m.history.md`, генератор слепка состояния, механику ухода терминальной фазы с живого пути · Границы: не трогает планы других проектов (D3) и не меняет команды — их правит P6; генераторы обязаны быть детерминированными и не звать модель

## DoR (Definition of Ready)

- [ ] Alternatives для несущих решений зафиксированы в D-логе.
- [ ] Open Questions разнесены по статусам `open-questions.md`.
- [ ] Несущие факты несут RAG-маркеры (`RAG:✅ …` / `RAG:— …` / `[UNVERIFIED]`).
