# Claude: компактный EN-канон из полного RU-источника

Тебе дан полный русский `SKILL.ru.md` — ИСТОЧНИК ИСТИНЫ скилла. Сгенерируй из него
компактный английский `SKILL.md` — канон, который грузит агент (русский он не видит).

## Контракт точности (ГЛАВНОЕ)
- **Ничего не теряется.** EN обязан передавать КАЖДОЕ условие, правило, шаг, запрет,
  порог, edge-case из RU. Поведение скилла идентично — меняются только язык и объём.
- **Ничего не добавляется.** Никаких новых правил/догадок, которых нет в RU.
- Если правило в RU неоднозначно — переноси как есть, не «улучшай».

## Компактность (для ИИ, не для человека)
- Императив, bullet-points, без вводной воды и пересказов.
- Убирай объяснения «почему» там, где есть прямая инструкция «что делать» (если «почему»
  не влияет на решение агента).
- Термины, имена, пути, команды, code-блоки, числа/пороги — БЕЗ изменений.

## Frontmatter
- Скопируй ВСЕ поля как есть, переведи на английский ТОЛЬКО значение `description`
  (компактно, конкретно — оно резидентно в каждом запросе, ярус ⊕ always).
- `name`, `bucket`, `version`, `risk`, `persona`, `tags`, `requires`, `produces_for`,
  `outputs`, `snippets`, `adapters`, `sha256`, `level` — НЕ трогай (если присутствуют).
  `level` (опц., core|foundation|extension) — скаляр, копируй как есть.

## Маркер источника
В самый конец файла добавь строку:
`<!-- ru-source-sha256: PENDING -->`
(хэш проставит `scripts/check-translations.sh --stamp` после сохранения — не вычисляй вручную).

## Выведи
Только содержимое `SKILL.md` (EN) — frontmatter + компактное тело + маркер. Без комментариев
вокруг.

> Проверка после: `scripts/check-translations.sh --stamp` (проставит sha) →
> `skiller registry` (перегенерит реестр + карту бюджета — увидишь падение ↻/⊕).
