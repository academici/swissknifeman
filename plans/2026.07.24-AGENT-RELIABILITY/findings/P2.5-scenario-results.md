## 6. Reproducibility (P2.8)

- Generator: `artifacts/P2.5/generate_transcripts.py` (committed, stdlib-only, no
  `time`/`random`/network/absolute-path literals in its logic). Two consecutive runs
  produce a byte-identical `transcripts.json` (verified locally; also the dedicated
  Validation step `generate_transcripts.py --out transcripts.json && git diff
  --exit-code`).
  Two subprocess calls are real, read-only checks over the already-committed tree
  (`plan-lint.py`, `packages/skiller/bin/skiller registry --check`) and are captured only
  as exit codes, never raw stdout — the source of non-determinism a raw-text capture
  would otherwise risk.
- Provenance: `result-manifest.json::input_provenance` records the generator's own path
  and sha256, `transcripts.json`'s sha256, and the tree anchor (`git rev-parse
  --short HEAD`) at seal time (`verify_result_manifest.py --transcripts --generator`,
  P2.8's extension of the existing hash checks) — a future regression of either input is
  a visible sha256/content_hash diff against this committed record, not silently
  swallowed.
- `run_bank.py`/`cases.json`/`graders.json`/`bank-manifest.json` remain byte-identical
  (D30, frozen; `git diff --exit-code -- artifacts/reliability-bank-v1
  artifacts/source-evidence` clean).
