# P5 — карта внешних факт-классов ДО поиска (слой 2, 2026-07-25)

Порядок обязателен по **D20**: сначала перечислить, какие классы ВНЕШНИХ фактов несёт фаза,
затем искать. DoR-гейт проверяет форму RAG-маркеров, а не полноту множества — эта карта и есть
проверка полноты. Файл написан ДО первого запроса; исходы проставлены ниже, после прогона.

Фаза P5 = пилот `tirth8205/code-review-graph` (MCP-граф кода) против сегодняшнего канона
графа кода — **Serena** (LSP через `uvx`, `packages/maind/lib/maind/codegraph.py`), с вердиктом
adopt/skip/combine и owner-гейтом (OQ-1, Обсуждение §2, D8).

## Что уже известно из репо (НЕ ищем — repo-grounded, подтверждается чтением кода/состояния)

- Канон графа кода — Serena, пиннована на релиз `v1.5.3`, ставится `uvx --from git+…`, поднимается
  per-project MCP-сервером `serena`, политика вся из секции `code_graph` конфига
  (`packages/maind/lib/maind/constants.py:47-77`, `codegraph.py:24-57`).
- Провиженер пишет `.serena/project.yml` ТОЛЬКО если файла нет; после активации файлом владеет
  Serena (`codegraph.py:140-170`) — то есть замена движка это смена `code_command`/`code_server_name`
  per-project, механизм подмены уже существует (`codegraph.py:41-57`, ветка `is_engine_serena`).
- Код-граф включён у **15 из 25** проектов реестра (`config.json`, поле `code:true`), из них
  5 laravel-project, 7 php-package, 3 node-package, 1 standalone (сам swissknifeman) — кандидаты
  пилота выбираются отсюда, а не «наугад».
- Измеритель резидентной цены MCP уже есть: `skiller budget --first-turn` (`budget.py::_measure_mcp`),
  гейт объявлен обязательным перед новым always-on инжектом (CLAUDE.md § «Рамки»).
- Место возможной врезки в ревью — `/task:review` Stage A/B (`packages/task/commands/review.md`),
  скилл-адресат вердикта — `general/mcp-advisor` (карта серверов + раздел «Прополка резидентного MCP»).
- stdlib-only — рамка **наших python-пакетов**; внешний MCP-сервер это отдельный процесс
  (`plan.md` §2 Execution Rules), поэтому его pip-природа сама по себе не блокер.

## Исходы прогона (заполняется ПОСЛЕ поиска, 2026-07-25)

| # | Исход | Где лежит |
|:--|:--|:--|
| FC-1 | **найдено — задаёт протокол замера.** Консенсус практики: baseline = grep+**read** (не голый grep); считать **per-task**, а не per-question; стратифицировать задачи (lookup · structural · hard impact/disambiguation); рядом с токенами мерить качество (точность по эталону, completion rate, F1 для set-задач). Фиксировать модель/промпт/версии, менять ТОЛЬКО провайдер контекста | `findings/P5-codegraph-vs-serena-facts.md` §7 |
| FC-2 | **найдено — снимает заявку как ожидание.** 82× = whole-corpus baseline, автором же названный «upper bound no real agent pays»; в репо ЧЕТЫРЕ разных токен-бенчмарка; реалистичный `agent_baseline` (grep top-3) **числами не опубликован** («not quoted before being measured»); формальный `token_efficiency` даёт **<1.0×** на мелких коммитах. Воспроизводимая команда eval есть | §3 |
| FC-3 | **найдено — исключает вариант «заменить Serena».** F1 0.714 / precision 0.578 при recall 1.0, который автор дисквалифицирует как круговой; co-change-режим есть в коде, чисел нет («expect those numbers to be substantially lower»); multi-hop 0.909 — 11 задач, курированных автором. Про LSP дословно: «LSP is more precise per symbol; CRG is broader, persistent». Названные слабости: MRR 0.35 поиска, flow detection 33%, оверпрогноз impact | §4 |
| FC-4 | **найдено — опровергает премису «дорогой резидент».** Tool search включён **по умолчанию**: «Only tool names and server instructions load at session start»; описания и инструкции режутся на 2KB; `alwaysLoad` — явное исключение с ценой; `ENABLE_TOOL_SEARCH` = unset/true/auto/auto:N/false. Наш `_measure_mcp` считает EAGER-потолок, то есть верхнюю границу | §6 |
| FC-5 | **найдено — цена другая, чем ожидалось.** Python ≥3.10, 7 обязательных pip-зависимостей (`fastmcp` с историей CVE и ломающей мажорки), SQLite в `.code-review-graph/`, build ~10 с/500 файлов, инкремент <2 с/2 900 файлов, `crg-daemon` для мульти-репо. **Главное:** `install` пишет не только `.mcp.json`, а ещё хуки, 7 скиллов и «injects graph-aware instructions into your platform rules» — это always-on инжект под наш гейт `budget --first-turn` | §2 |
| FC-6 | **найдено — риск-класс «молодой популярный проект».** 26.3k★, MIT, создан 2026-02-26 (5 месяцев), 116 открытых issues, поток контрибуций выше пропускной способности мейнтейнера (его же документ про 104 PR / 84 issues); SemVer-теги есть → версия пиннуема. Телеметрии нет, сеть только opt-in (облачные эмбеддинги). **Независимых сторонних отчётов/бенчмарков не найдено — все публичные числа самозамер** | §1, §2, §7 |
| FC-7 | **найдено — покрытие есть, глубина не подтверждена.** Composer PSR-4 (repository-bounded), Blade-ссылки, **evidence-gated** Laravel Route→controller и Eloquent-рёбра; flow detection «strongest for Python and PHP/Laravel». Поведение на динамической магии (фасады/`resolve()`/макросы) из формулировки не следует — помечено `[UNVERIFIED]` до пилотного замера | §5 |
| FC-8 | **найдено — рынок не консолидирован.** Соседи: Serena (LSP, наш канон), codegraph (несколько разных проектов под одним именем), claude-context (вектор-БД + провайдер эмбеддингов), repomix (упаковка репо, Node). Независимого лидера класса нет; разведка новых кандидатов — вне скоупа фазы, репо названы, чтобы вердикт их не игнорировал | §8 |

**Что карта дала сверх «просто поиска» (проверка D20-механики):** три класса оказались
дизайн-меняющими, и ни один не следовал из формулировок контракт-блока P5. FC-4 **перевернул
замер «а»**: контракт предполагал, что резидент — это цена 30 схем инструментов, а first-party
говорит, что при дефолтном tool search резидентны только имена и server instructions; настоящий
always-on риск нашёлся в другом месте (FC-5: `install` правит правила платформы и ставит 7
скиллов). FC-2 снял ожидание «×82» как основание вердикта: реалистичный baseline автором
измеряется, но не публикуется. FC-3 закрыл вариант «adopt вместо Serena» ещё до пилота —
автор сам называет LSP точнее per-symbol. Четвёртый датированный кейс в пользу правки,
запланированной P6.3.
