## Решение

The canonical Skill Core is the minimum sufficient provider-neutral contract: one job, a
discriminative trigger/negative boundary, explicit inputs/outputs, non-obvious invariants/risk,
capability requirements and on-demand resources. Generic model behavior, repeated examples and
legacy guardrails are removed unless official requirements, repository invariants, observed
failures or ablation justify them. `Failure modes` is evidence-backed and optional, never universal
boilerplate. RAG:✅ 2026-08-10 official Anthropic/OpenAI verification in findings/13.

## Почему

Current models benefit from high-signal interfaces and progressive disclosure; blanket prompt
accumulation creates conflicts and context cost.
