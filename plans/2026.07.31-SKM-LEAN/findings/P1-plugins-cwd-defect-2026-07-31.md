# P1 — разбор дефектов агрегатора плагинов на живом CLI (2026-07-31)

**Слой 1 (сырьё).** Живой прогон `claude 2.1.220` (`/home/vostrikov/.local/bin/claude`),
2026-07-31, сессия ре-дизайна P1.2 (opus/high). Повод — эскалация P1.2:
`plugins.partial: true` на 22/22 строк флот-обхода. Все числа ниже сняты вызовами,
приведёнными дословно; воспроизводимость — при неизменном наборе установленных плагинов
(состав плагинов среды меняется независимо от репозитория).

Проверялись три утверждения эскалации P1.2 и одно утверждение докстринга P1.1. Итог:
**эскалация подтверждена полностью, докстринг P1.1 опровергнут частично** (§4).

## 1. `claude plugin details` ЗАВИСИТ от CWD в части резолвинга

Плагин `architect@swissknifeman` — `scope: local` проекта `memster`
(`/home/vostrikov/projects/memster`), в реестре плагинов swissknifeman его нет.

```
$ claude plugin details architect@swissknifeman        # cwd = swissknifeman
Plugin "architect@swissknifeman" not found. Run `claude plugin list` to see installed plugins, …
rc = 1

$ cd /home/vostrikov/projects/memster && claude plugin details architect@swissknifeman
architect
  …
  Always-on:   ~1,275 tok   added to every session
rc = 0
```

**Вердикт:** `plugin_always_on_tokens` (`packages/skiller/lib/skiller/plugins.py:79`) зовёт
`_run_claude(["plugin", "details", plugin_id])` БЕЗ `cwd` → для local-scope плагинов любого
проекта, кроме того, из которого физически запущен `skiller`, цена не берётся. Это и есть
причина `partial` на всём флоте: обход запускался из swissknifeman, а измерялись чужие
проекты.

## 2. Значение ЦЕНЫ от CWD не зависит

Плагины, резолвящиеся из обоих CWD, дают побайтово одинаковую строку:

| id | scope | из swissknifeman | из memster |
|:--|:--|--:|--:|
| `codex@openai-codex` | user | ~449 tok | ~449 tok |
| `core@swissknifeman` | local | ~869 tok | ~869 tok |
| `maind@swissknifeman` | user | ~450 tok | ~450 tok |
| `task@swissknifeman` | local/project | ~959 tok | ~959 tok |

**Вердикт:** кэш успешного результата по `id` (P1.1 Implementation Rules §5) остаётся
законным — от CWD зависит РЕЗОЛВИМОСТЬ, а не число. Кэшировать по `id` НЕУДАЧУ — нельзя:
тот же `id` под другим `cwd` резолвится (§1).

## 3. Формат числа несёт разделитель тысяч

Наблюдённые строки (memster, 2026-07-31): `~98`, `~219`, `~225`, `~267`, `~326`, `~331`,
`~382`, `~435`, `~449`, `~450`, `~769`, `~869`, `~950`, `~959`, `~1,059`, `~1,275`, `~1,789`.

`_ALWAYS_ON_RE = ^\s*Always-on:\s*~(\d+)\s*tok\b` (`plugins.py:20`) не матчит `~1,275`:
строка уходит в `unparsed`, три самых дорогих плагина выпадают из суммы даже при верном
`cwd`. Суффиксной формы (`~1.1k`) в этом замере по-прежнему НЕ наблюдалось (максимум —
`~1,789`); угадывать множитель по-прежнему нет основания.

## 4. Что именно опровергнуто в P1.1

Докстринг `plugin_always_on_tokens`: «`details` описывает ПЛАГИН, не проект, и от CWD не
зависит». Первая половина верна (§2 — число одинаково), вторая ложна (§1 — резолвится
только под своим проектом). Вывод для починки: `cwd` пробрасывается, кэш по `id`
сохраняется ТОЛЬКО для успехов.

## 5. `brain@brain` — сломанный апстримом плагин, а не дрейф формата

`claude plugin list --json` из ЛЮБОГО проекта отдаёт запись:

```json
{"id": "brain@brain", "scope": "user", "enabled": true,
 "errors": ["Plugin brain has an invalid manifest file at
             /home/vostrikov/Vaults/Brain/.claude-plugin/plugin.json.\n\n
             Validation errors: commands: Invalid input, skills: Invalid input"]}
```

`claude plugin details brain@brain` → `rc = 1`, «not found» — из swissknifeman И из memster.

**Следствие, определяющее конструкцию (несущее):** плагин `scope: user`, то есть в листинге
КАЖДОГО проекта флота. Значит и после починки §1/§3 хотя бы одна цена останется невзятой на
100 % строк — `partial: true` будет гореть всегда, а гейт, который горит всегда, не гейт (та
же болезнь, что у порога `first-turn`, ради которого затеяна фаза). При этом сам листинг
объявляет запись сломанной полем `errors` — источник для отдельного класса неполноты уже
есть, его не надо угадывать. Дефект живёт в ЧУЖОМ репозитории (`brain`,
`~/Vaults/Brain/.claude-plugin/plugin.json`) — вне периметра этого плана.

## 6. Масштаб занижения (контрольный проект `memster`)

Обход всех `enabled`-записей `memster` под его собственным `cwd`: 17 уникальных `id`

резолвится 16, не резолвится 1 (`brain@brain`, §5).

Сумма 16 резолвящихся: **10 852 ток**.

Занижение — **3,7×**; `session_total` memster 25 415 → ≈ 33 321. Тот же класс занижения на
всех 22 измеренных строках (значение 2 946 повторяется по флоту — это ровно те плагины,
что резолвились из CWD сборщика).

## 7. Стоимость вызова (вход для таймаута обхода)

`claude plugin details <id>` — ~0,76 с; `claude plugin list --json` — ~0,21 с (замер `time`,
memster, 2026-07-31). Кэш `_details_cache` — модульный, живёт в ПРОЦЕССЕ: флот-обход
запускает `skiller` отдельным процессом на проект, значит кэш между проектами не переносится
и каждый проект платит своими ~17 вызовами ≈ 13 с плюс `SessionStart`-хуки (таймаут 10 с).
Пер-проектный таймаут 30 с в `artifacts/p1-2-fleet-sweep.sh` после починки станет слишком
тесным — вход для P1.2.
