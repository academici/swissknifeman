# P1 — Active-plan migration and Layout v1 execution retirement

## Phase Context

P1 выполняет one-way cutover: inventory всех active plan roots уже закрыт P1.1,
а оставшийся путь разделён на узкую grammar compatibility, full-fleet admission policy,
контролируемые external writes и только затем retirement. Каждый Layout v1 сначала
получает byte-exact source archive, explicit transformation policy и green dry-run; запись
в target отделена от разработки и проверяет preimage digest. Архивные v1 остаются
inert Git bytes; unrelated contracts со schema version `v1` не входят в retirement. RAG:✅
2026-08-12 (Perplexity Web + Microsoft Durable Functions version retirement; findings/02).

**Scope Included:** repository + registered fleet inventory, closed migration policy, safe v1→v2 conversion, controlled target writes, generated carriers, v2-only layout resolver/lint/read path/commands/docs/tests.

**Scope Excluded:** переписывание archived v1 history; удаление `task-contract/v1`, receipt/v1 или других не-layout контрактов; unregistered filesystem scanning.

> **Контракт фазы (contract-first).** Потребляет: P0 acceptance/RAG · Производит: zero-active-v1 proof + v2-only Task runtime · Границы: migration before reader removal.
