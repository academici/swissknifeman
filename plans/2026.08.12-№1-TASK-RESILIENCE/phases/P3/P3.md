## Phase Context

гипотеза остаются append-only evidence, но не закрывают и не блокируют item. Затем пять
canonical commands получают один continue-first algorithm. Фаза не разрешает terminal block — это
отдельная P4. Она также убирает ложный workflow warning, когда orchestration явно отрицается.

**Scope Included:** journal enum/schema, state reducer, attempts, command conflict-impact/local-repair loop, route undershoot, RAG-pending semantics и negation-aware orchestration declaration lint.
