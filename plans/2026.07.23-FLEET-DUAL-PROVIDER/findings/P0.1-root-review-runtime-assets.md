# P0.1 root-review — runtime support files

**Дата:** 2026-07-23

После attempt 1 независимая проверка сопоставила claim «self-contained selected
bundles» с реальными каталогами скиллов. `_codex_bundle_artifacts` включал только
`.codex-plugin/plugin.json` и найденные `SKILL.md`, поэтому runtime-зависимости
скиллов (`snippets/`, `references/`, scripts/assets) не попадали во внешний
consumer bundle.

Наблюдаемый пример:

- `packages/skiller/skills/quality/tdd-discipline/SKILL.md` ссылается на
  `snippets/tests.md`, `snippets/mocking.md` и `snippets/refactoring.md`;
- исходный plugin bundle содержит эти файлы;
- artifact list attempt 1 их не перечисляет, следовательно consumer получает
  инструкции со сломанными относительными ссылками.

Вердикт: P0.1 attempt 1 не подтверждает frozen contract requirement
`self-contained`; item переоткрыт для test-first fix-forward. Repair должен
доставлять runtime support files под declared skill roots, сохранять containment
и существующие registry-only exclusions (`upstream.json`, `.claude-plugin`,
`SKILL.*.md`, `evals`, `__pycache__`, `*.pyc`).
