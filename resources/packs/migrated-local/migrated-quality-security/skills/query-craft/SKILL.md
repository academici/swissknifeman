# Query craft

Use when a search needs more precision. Verification triggers and source choice
belong to `general/verify-claims`; do not repeat its procedure here.

Name the concrete question, library/tool and installed version when relevant,
environment constraints and desired evidence. Add a date range only when freshness
matters. Read a project manifest before guessing a version. If the task is to find
the current version, ask that explicitly. Request primary-source links and a bounded
answer. Follow up on a missing fact instead of repeating a broad research query.

Example: `Laravel 11 + Pest 3: how does RefreshDatabase select the database connection?
Official implementation/docs; show the setting that controls it.`
