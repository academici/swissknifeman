# P7 — Docs, self-hosting validation и FOREMAN release gate

## Phase Context

P7 завершает migration только на проекте `swissknifeman`: генерирует публичную provider
capability matrix из запечатанного semantic source, затем проводит isolated и live self-host
install/update/check/repair для Claude Code и Codex. Временные bootstrap surfaces удаляются
только после доказанного ownership/provenance и только когда их заменяет generated managed
output; user-owned и legacy compatibility carriers сохраняются. Финальный item независимо
сверяет contracts, docs, E2E, protected-path delta и release manifest, после чего владелец
принимает GREEN/ATTENTION/RED verdict. GREEN открывает только отдельный reconcile-заход
FOREMAN; эта фаза не исполняет FOREMAN и не начинает fleet rollout.
Instruction contract/catalog/markers/hash/repair semantics уже созданы P5.6/P5.7 и
интегрированы P6.2/P6.5/P6.6; P7 запрещено впервые проектировать или переопределять их.

independent doc drift/parity check; isolated dual-provider self-host plan/check/apply/repair;
live swissknifeman-only apply с backup/rollback; Claude compatibility; Codex native surfaces;
task smoke tests; analytics/provenance evidence; bootstrap ownership inventory и cleanup;

adversarial verdict; explicit owner gate для FOREMAN reconcile.

**Scope Excluded:** новые provider semantics; изменение frozen P0–P6 contracts без reopen;
ручное обслуживание двух provider trees; удаление user-owned/legacy carriers; package feature

`plans/2026.07.18-FOREMAN`; запуск FOREMAN items; fleet writes;
