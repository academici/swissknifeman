Planner plan (layout v4): authoring and lifecycle verbs.

positional arguments:
  VERB

                        arguments
    set                 merge-patch plan, brief, a phase, item, decision or
                        unit
    apply               validate and apply a JSON array of {ref, patch} edits
                        together
    export              export the complete plan as a current-format JSON

    import              import a current-format JSON snapshot into the
                        specified directory
    add-document        add a schema-backed knowledge document
    link                add a typed link between two documents of the plan; a

    unlink              remove a typed link between two documents of the plan;

    add-artifact        declare an input or output artifact of an item; a

    push                append a value to an array field (dotted paths

    add-decision        add a decision or open question
