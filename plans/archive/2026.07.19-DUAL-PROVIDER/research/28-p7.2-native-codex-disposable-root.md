**Scope:** bounded P7.2 redesign after the fresh 2026-07-23 probe. This document does
not execute a marketplace add, plugin install, apply, repair, rollback, or live mutation.

## Evidence and decision

The fresh probe establishes that the non-native disposable matrix is green, but correctly
stopped before native Codex marketplace installation because using configured host Codex
state would violate the P7.2 disposable-root rule. `codex plugin --help` exposes only
configuration overrides and does not itself advertise a state-root flag.

The current official Codex manual documents `CODEX_HOME` as the configuration/plugin state
root: profile configuration lives under `$CODEX_HOME`, and its CI plugin examples provision
the plugin with `CODEX_HOME` set to a runner-temporary `codex-home`. Therefore the supported
isolated route is environment selection, not a speculative `-c` key or a host-state fallback.

## Prescribed native segment

For each native Codex marketplace row, the executor creates one task-specific directory
under a task-temp parent and exports it only for that command sequence:

```bash
P72_CODEX_HOME="<task-temp>/codex-home"
env CODEX_HOME="$P72_CODEX_HOME" HOME="<task-temp>/home" \
  codex plugin marketplace add /home/vostrikov/projects/packages/swissknifeman
env CODEX_HOME="$P72_CODEX_HOME" HOME="<task-temp>/home" \
  codex plugin add core@swissknifeman
```

The actual plugin ID(s) and marketplace path are resolved from the frozen P3/P7.1 catalog
before execution; the shown `core@swissknifeman` is the already-probed native example, not
a license to add other plugins. The executor snapshots the task-temp root before the first
command, records only IDs/hashes/exit statuses (never credentials), proves the installed
plugin is read from that `CODEX_HOME`, and removes/moves only that explicit task-temp root
into the task-local rollback capture. It must verify that repository, `/home/vostrikov/.codex`,
and other host-state paths have zero delta.

If the installed runtime disregards `CODEX_HOME`, writes outside the declared temp root, or
cannot authenticate without reading host state, the native row is `RED`: do not substitute a
host installation, do not derive the live action inventory, and preserve P7.2 as in progress
with the evidence and an owning-surface escalation.

## Boundary

This route authorizes neither a live marketplace install nor the existing P7.2 live
path/action gate. It only completes the required isolated native marketplace segment before
that later Approval Owner D# can be requested.
