# Discovery needs repository core on PYTHONPATH

The bare `cd packages/task && python3 -m unittest discover -s tests` command did not
import repository `core`, causing six unrelated adapter/contract import errors. This is
an invocation defect, not a task runtime regression: `validate.sh` already supplies
`packages/task/lib` and the monorepo root. P4.4 repeated discovery with that same path
and got 653 passing tests.
