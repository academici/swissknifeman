### P7.1 — bootstrap-machine.sh: идемпотентное развёртывание одной командой

**Status:** 🟢 Done
**Intent:** Скрипт `scripts/bootstrap-machine.sh` (+ роут `swissknifeman setup --machine`): после клона репо одной командой развернуть машину — install.sh (пакеты+симлинк) → `harness hooks --global` → `harness permissions --global` → глобальные MCP-пресеты → установка/запуск демона mAInd → финальный `swissknifeman doctor`; флаги `--dry-run` и `--skip-projects`.
**Why:** Переустановка ОС/вторая машина/команда сейчас = ручная невоспроизводимая цепочка; dotfiles-паттерн 2026 — один идемпотентный скрипт с merge-семантикой и dry-run (RAG:✅ 2026-07-12 findings/P0-rag-bootstrap-memory-sync.md).
**Scope Included:** новый scripts/bootstrap-machine.sh; роут в bin/swissknifeman (`setup --machine`); идемпотентность (повторный запуск = no-op/update); --dry-run; смоук-тест.
**Scope Excluded:** клонирование/онбординг зависимых проектов (P7.2 — манифест); межкомпьютерная память (D12); секреты/API-ключи (env-инструкция в доках, не в скрипте); поддержка не-Linux (macOS — best-effort пометка, не гейт).
**Inputs:** Существующие строительные блоки: корневой install.sh (делегирует install.sh пакетов, владеет симлинком swissknifeman); `harness hooks --global` (ставит ~/.claude/hooks/* включая agent-router v2); `harness permissions --global`; maind doctor/daemon-команды (packages/maind/CLAUDE.md). Bootstrap НЕ дублирует их логику — оркестрирует вызовы.
**Files:** scripts/bootstrap-machine.sh (новый) · bin/swissknifeman (роут setup --machine) · install.sh (только если нужен hook-пойнт, не переписывать)
**Required Reads:** 1) install.sh (корневой) 2) bin/swissknifeman (структура router'а) 3) packages/harness/CLAUDE.md (hooks/permissions --global) 4) packages/maind/CLAUDE.md (демон, doctor) 5) findings/P0-rag-bootstrap-memory-sync.md
**Implementation Rules:** bash, set -euo pipefail; каждая ступень объявляет себя и проверяема отдельно; merge-not-overwrite для JSON-конфигов (существующие механизмы harness — не изобретать свой merge); существующие файлы пользователя не затирать (паттерн репо: merge-only, бэкап *.bak); никаких секретов в скрипте/репо.
**Code Guidance:** Идемпотентность — гейт item'а: ЗАПРЕЩЕНО закрывать 🟢 без подтверждённого двойного прогона (второй прогон — 0 деструктивных изменений; артефакт — лог обоих прогонов). Скрипт — тонкий оркестратор: логика остаётся в пакетах, bootstrap только вызывает их CLI в правильном порядке и проверяет rc; дубль логики install/harness/maind в скрипте = дефект (рамка «единый источник истины»). --dry-run печатает план действий без выполнения (какие ступени, что обнаружено уже настроенным). Смоук: прогон в чистом $HOME (контейнер или HOME=$(mktemp -d) где применимо) — до doctor-ступени; ступени, требующие живого Claude Code, при недоступности — warn+skip, не fail (мягкая деградация как в eval-харнесе).
**Validation:** двойной прогон на чистом окружении: первый — все ступени OK, второй — идемпотентный no-op; `swissknifeman doctor` после прогона зелёный (или явные warn по отсутствующим внешним зависимостям); bash -n; `--dry-run` не пишет на диск (проверить mtime/дифф).
**Deliverables:** bootstrap-machine.sh + роут + лог двойного прогона в Completion Notes.
**Completion Notes:** `scripts/bootstrap-machine.sh` (6 ступеней: install.sh → `harness hooks --global`
→ `harness permissions --global` → MCP-пресеты (soft-skip, см. Known Deviations) → `maind service
