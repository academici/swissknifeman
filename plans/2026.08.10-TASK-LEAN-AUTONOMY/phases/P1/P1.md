# P1 — Minimal runtime alignment and field canary

## Phase Context

Фаза переносит Skiller-owned semantics в Task commands/runtime, устраняет только противоречащие
state/review переходы и затем применяет результат к живой работе. P1.1 исполняется только из
`packages/task`; P1.2 работает из repository root и не пишет package code. Итоговый verdict
объединяет focused checks с фактической траекторией и bounded replay реальных случаев.

**Scope Included:** Task plan-команды, procedural routing outcome, material review trigger/reuse,
focused tests, field canary и release-visible changelog.

**Scope Excluded:** универсальный supervisor, migration/archive rewrite, exhaustive model eval,
новая телеметрическая платформа и исправление несвязанных проблем canary-проектов.

> **Контракт фазы (contract-first).** Потребляет: terminal P0 semantics и D1–D8 · Производит: согласованные Task commands/runtime и GO либо ADJUST field verdict · Границы: P1.1 владеет всеми package fixes; P1.2 пишет только root evidence/changelog, а ADJUST остаётся nonterminal owner decision без автоматического audit loop.
