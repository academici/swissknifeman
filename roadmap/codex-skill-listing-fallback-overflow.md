## Контекст

`2026.07.29-HARNESS-AGNOSTIC P3.4` добавил в `packages/skiller/lib/skiller/budget.py`
provider-aware модель бюджета обнаружения (листинга): у Claude Code (уже было,
`2026.07.25-ECO-OPT` P3.4) — 1% контекстного окна в ТОКЕНАХ (30 000 симв @1M);
у Codex (RAG:✅ `learn.chatgpt.com/docs/build-skills`, 2026-07-29) — **2% окна в
СИМВОЛАХ, фолбэк 8 000 симв, когда окно неизвестно** — и режим деградации хуже:
Codex может **выбросить скилл из листинга целиком**, тогда как Claude Code лишь
усекает описание, сохраняя имя.

## Почему рычаги 1–3 владельца (D74) не закрывают Codex

Порядок рычагов владельца (`2026.07.25-ECO-OPT` D74): (1) сузить набор → (2)
`skillOverrides: "name-only"` → (3) `skillListingBudgetFraction`/
`SLASH_COMMAND_TOOL_CHAR_BUDGET` → (4) сжатие описаний, последним.

- **(1) Сузить набор** — уже исполнено для Claude-оси (ECO-OPT P3.5); дальнейшее
  урезание бьёт по составу раздачи 25 онбордженных проектов и не входит в
  гигиену реестра (D29).
- **(2) `skillOverrides: "name-only"`** — **Claude-only рычаг** (first-party
  Claude Code), у Codex такого параметра нет вовсе — не переносится.
- **(3) `skillListingBudgetFraction`/`SLASH_COMMAND_TOOL_CHAR_BUDGET`** —
  Claude-специфичные настройки; аналог для Codex first-party не документирует.
- **(4) Сжатие описаний** — арифметически не спасает `laravel-project`: чтобы
  76 скиллов уложились в 8 000 симв, на запись остаётся ~105 симв вместе с
  именем и путём — меньше сегодняшнего среднего (219) и на грани нечитаемого
  триггера (см. `findings/04-rag-agent-surface-and-skill-listing-2026-07-29.md`
  §«Замеры реестра», D29).

Значит для Codex реально применимы только: сужение специфично под Codex-раздачу
(не общее сужение профиля) или **принятая деградация** (осознанно смириться с
тем, что часть скиллов невидима в листинге Codex до первого явного вызова).

## Варианты (решение владельца)

1. **Codex-специфичный урезанный профиль** — отдельный, более узкий состав
   бакетов только для проектов, где Codex — основной драйвер (цена: второй
   набор профилей на сопровождении, дрейф между Claude- и Codex-версией).
2. **Принятая деградация** — записать явно: на Codex часть редко используемых
   скиллов может быть не видна в листинге до точечного вызова по имени; цена —
   тихий провал auto-routing на конкретных задачах, которую нельзя измерить без
   живого прогона Codex CLI (round-trip вне скоупа, D3).
3. **Не выбирать сейчас** — оставить как измеренный, документированный разрыв
   паритета (WARN-гейт `validate.sh` §17 держит число видимым на каждом
   прогоне) и вернуться, когда появится живой сигнал (round-trip Codex CLI,
   OQ-7 переоткрывается по факту, не по календарю).
