# Ревью прогона фазы P11 дирижёром orch: какой промпт кому

Два самостоятельных промпта, каждый содержит весь нужный контекст и список материалов. Ветка `ecosystem-split`, push не делался.

| Файл | Модель | Что делает |
| --- | --- | --- |
| [`orch-p11-review-prompt-sonnet.md`](orch-p11-review-prompt-sonnet.md) | **Claude Sonnet 5.5, effort high** | сверяет каждое из ≈40 спорных решений и коммиты пунктов P11.4–P11.15 с кодом; проверочная работа по чек-листу; независима по пунктам, можно параллелить несколькими сессиями |
| [`orch-p11-review-prompt-opus.md`](orch-p11-review-prompt-opus.md) | **Claude Opus 5.5** | оценивает механизм оркестрации (≈65 правок) и таблицу правок инструкций; вопросы архитектурные |

Почему две модели: часть A — работа по чек-листу с чтением диффов и запуском тестов, где Sonnet почти не уступает Opus и дешевле;
часть B — архитектурные вопросы и независимость: автор правок (наблюдатель) — Sonnet 5.5, а ревьюер той же модели разделяет его
слепые пятна. Если нужна одна сессия: Opus 5.5 по файлу B, затем решения по пунктам из файла A выборочно; если бюджет минимален —
только файл A на Sonnet 5.5 (решения по механизму тогда менее независимы).

Материалы лежат в `docs/`: `orch-p11-observer-journal.md` (хронология решений и ошибок), `orch-p11-run-findings.md` (каталог
дефектов, профили, расход, оценки, спорные решения, правки инструкций), в `packages/orch/docs/conductor.md` (опции движка), скилл
`packages/orch/dev-skills/orch-debug/SKILL.md`, инструменты `packages/orch/scripts/{run-usage,step-profile}.py` и
`scripts/affected-tests.py`.
