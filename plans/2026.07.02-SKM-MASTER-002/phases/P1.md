# P1 — Plan-протокол (фаза A)

## Phase Context

Строим носитель протокола исполняемых мастер-планов: скилл `general/plan-protocol` (SSOT схем,
статусов, routing-матрицы, эскалации), детерминированный валидатор `plan-lint` в пакете task,
4 команды `/task:plan-{design,exec,close,audit}` (frontmatter пинит model/effort), bootstrap
самого этого плана в `plans/2026.07.02-SKM-MASTER-002/` (dogfooding) и пилотный цикл exec→audit на sonnet.
Архитектурные решения фазы: MD-only (D3), файл-на-фазу (D4), протокол живёт в скилле —
план несёт данные, plan-exec самозакрывающийся (D5). Статусы — РОВНО 6 канонических строк.
Эскалация — greppable-блок `> 🔴 ESCALATION Pn.m: … | trigger: <enum> | нужен: plan-design`
+ Status 🔴 Blocked + финальная строка отчёта `ESCALATION-REQUIRED`. Фаза завершена, когда
sonnet проходит полный цикл plan-exec → закрытие item без импровизации, plan-audit даёт GREEN,
а cold-start (/clear) продолжается только из файлов плана.
