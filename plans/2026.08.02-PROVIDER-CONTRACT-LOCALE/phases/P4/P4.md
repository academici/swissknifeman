# P4 — Implement locale rendering and English canonical migration tooling

## Phase Context

P4 implements the frozen P2 locale/authoring contracts on top of terminal P3 control-plane
and status interfaces. Execution is closed until P0–P3 are terminal and the exact frozen
P2/P3 contract files and item commits named below exist. Locale resolution is a shared,
stdlib-only domain: packages and providers receive one immutable per-surface context but keep
ownership of their own source catalogs and rendered targets. Migration is admission-led, not
a bulk translation: every canonical unit needs an owner, preimage, immutable-token proof,
independent English/Russian review and rollback before it can change. Six items form one
sequential chain through a cumulative ledger, ending in a single regeneration/readback item.
The phase never mutates a consumer project, user locale state, provider trust/credentials or
another provider's files; those remain P5/P6 concerns.

P4.1–P4.6 use the D39 per-cwd carrier in `roadmap.md`; the root coordinator owns
integration, the cumulative ledger and item closure, while package mutations occur only from
fresh package-cwd sessions. P4.3–P4.6 additionally use D40 bounded ledger batches. Every batch
has a committed manifest/checkpoint, a distinct read-only reviewer record and deterministic
resume pointer; no next batch starts before the prior one is accepted.

**Scope Included:** shared locale values/resolution/catalog/rendering; plan/response/diagnostic
render contexts; English-source and sparse-overlay validators; owner/preimage/review/rollback
migration tooling; reviewed migration of skills, commands/plugins/diagnostics, code prose and
development docs; terminal regeneration and two-provider readback.

**Scope Excluded:** changing frozen P1/P2/P3 contracts; reading environment/filesystem inside
the pure resolver; provider/fleet rollout; translating IDs, paths, commands, schemas, keys,
diagnostic/action codes, placeholders or parser literals; automatic translation/self-review;
deleting an unadmitted RU source or local override; credential/trust repair.

> **Контракт фазы (contract-first).** Потребляет: terminal P0–P3; frozen `provider-control-plane-v1`, `locale-resolution-v1`, `english-authoring-overlay-v1`, `locale-authoring-review-v1`; P2 carrier matrix/checker; P3 desired snapshot and redacted diagnostics · Производит: shared locale runtime, provider-owned render integrations, canonical admission ledger/migration tooling, reviewed English-source corpus, generated projections and P5/P7 acceptance evidence · Границы: no contract rewrite, consumer/fleet mutation, provider trust/credential action, local-override adoption or cross-provider write.
