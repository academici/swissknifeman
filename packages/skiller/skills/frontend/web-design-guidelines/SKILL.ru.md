# Web Interface Guidelines (Руководство по веб-интерфейсам)

Проверка файлов на соответствие Web Interface Guidelines (Руководству по веб-интерфейсам).

## Как это работает

1. Загрузить актуальные рекомендации по приведённому ниже исходному URL
2. Прочитать указанные файлы (или запросить у пользователя файлы/шаблон)
3. Проверить по всем правилам из загруженных рекомендаций
4. Вывести найденное в лаконичном формате `file:line`

## Источник рекомендаций

Перед каждой проверкой загружайте свежие рекомендации:

```
https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md
```

Используйте WebFetch, чтобы получить актуальные правила. Загруженный контент содержит все правила и инструкции по формату вывода.

## Использование

Когда пользователь передаёт аргумент-файл или шаблон:
1. Загрузить рекомендации по исходному URL выше
2. Прочитать указанные файлы
3. Применить все правила из загруженных рекомендаций
4. Вывести найденное в формате, заданном в рекомендациях

Если файлы не указаны, спросите у пользователя, какие файлы проверять.
