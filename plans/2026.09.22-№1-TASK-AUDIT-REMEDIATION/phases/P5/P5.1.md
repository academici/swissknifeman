**Implementation Rules:** Frozen policy, not manifest/caller, owns whether minimization is mandatory and which sensitive classes are prohibited/allowed. Caller declarations are assertions checked against observed bytes and policy, never policy input. Normalize manifest paths before opening; reject empty/duplicate/absolute/traversal/file URI and platform-external forms. Use `lstat`/no-follow semantics and require declared members to be contained regular files; canonical resolved target must remain within bundle root when resolution is allowed. Preserve every execution input in compiled contract with explicit `internal|external|invalid` kind and original normalized representation; portability gate rejects external/invalid entries with specific codes. Avoid expanding environment/home strings into ambient secrets. Measure existing bundle fallout and provide deterministic regeneration/migration rather than weakening. Edit canonical source first and regenerate runtime projection through its owner; never hand-edit generated bootstrap projections.
**Code Guidance:** Build one path-classification result type consumed by compiler and lint instead of scattered booleans. Use platform-neutral lexical tests even on Linux for drive-letter/UNC/file URI forms, plus filesystem tests for symlink escape, broken symlink, FIFO/device where safely creatable, duplicate aliases and valid nested files. Sensitive-byte fixtures use unmistakably fake markers and minimal content; do not commit realistic secrets or raw transcripts. Structural source-template assertions remain unit tests, not evidence of prompt effectiveness.
**Validation:** 1) Focused tests cover one sensitive transcript, caller policy tampering, one lexical external path, one symlink escape and one valid minimized nested bundle; 2) a small compatibility sample includes the current P1/P2 bundles rather than scanning every historical plan; 3) `python3 -m unittest discover -s packages/task/tests -v` and `bash packages/task/scripts/validate.sh`; 4) run the pinned Edufy P14.3 task in isolated paired worktrees and require its real feature/arch validations or an actionable safe refusal; 5) record results in `findings/P5-privacy-portability-results.md`; 6) plan bundle/lint and `git diff --check` GREEN.
