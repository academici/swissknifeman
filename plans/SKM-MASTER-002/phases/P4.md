# P4 — Analyst learning loop (фаза D)

## Phase Context

Замыкаем learning loop analyst поверх телеметрии (P2) и патологий (P3): команда
`analyst token-report` (срезы по model/role/phase, двухслойный baseline: rolling медиана+p90
K=20 и pinned через `--baseline set`), агент-аналитик `analyst.md` + команда `/analyst:deep`
(digest-first: скрипты дают JSON, raw-транскрипты запрещены — D16), `analyst ingest` для
findings агента (только ephemeral-уроки, промоут остаётся за человеком) и `analyst proposals`
(типы stack-pack/project-override/docs; каталог `~/.swissknifeman/analyst/proposals/`;
analyst никогда не пишет в шаблоны/проекты — печатает handoff-последовательность).
Алертинг регрессий: maind analyze reason `⚠ токены ×N` при >max(1.5×median, p90);
digest token-regression при ≥3/5 сессий над порогом. Инварианты пакета неприкосновенны:
человек в гейте промоута, privacy (сырьё LOCAL), детерминированный stdlib-слой.
Агент — экосистемно-единый (в пакете analyst, раздаётся marketplace), запуск on-demand
(после ATTENTION-серии/еженедельно), НЕ per-session. Фаза завершена, когда token-report
рисует таблицу с baseline, /analyst:deep работает digest-first, а proposals не пишут вне
своего каталога.

### P4.1 — analyst token-report + двухслойный baseline

**Status:** ⬜ Not started
**Intent:** Команда `analyst token-report` (`token_report.py`): `[--sessions N] [--by model|role|phase] [--vs-baseline] [--all-projects] [--json]` + baseline rolling/pinned.
**Why:** Токен-регрессии должны быть видимы одной командой; baseline двухслойный — rolling ловит дрейф, pinned фиксирует «до/после» внедрений.
**Scope Included:** чтение usage-trend; срезы: role = label агента, phase = workflows[].name; regression-флаг при >1.3×baseline_median или >p90; `--baseline set --note …` → `.claude/analyze/baseline.json`; JSON-вывод; reason `⚠ токены ×N` в maind analyze при >max(1.5×median, p90).
**Scope Excluded:** digest token-regression detector (порог ≥3/5 сессий — контур P3.3, здесь только источник числа); OTel/экспорт.
**Inputs:** зависит от P2.2 (trend существует). Пин baseline после приземления бакетов/паков — шаг в release-discipline как proposal (не автоматизировать здесь).
**Files:** packages/analyst/lib/analyst/token_report.py · packages/analyst/lib/analyst/cli.py · packages/maind/lib/maind/analyze.py (reason)
**Required Reads:** 1) packages/analyst/lib/analyst/cli.py (диспетчер команд) 2) формат usage-trend (P2.2, hooks/run-report) 3) packages/analyst/lib/analyst/status.py (стиль табличного вывода)
**Implementation Rules:** stdlib-only; baseline.json — атомарная запись core.io; без тренда — вежливый die с подсказкой как включить хук.
**Code Guidance:** Медиана/p90 — statistics из stdlib (p90 — quantiles n=10); таблица — выравнивание f-строками, не сторонние либы; --json печатает чистый JSON без декора; пустое окно сессий — честное сообщение, не нули; тесты на regression-флаг с синтетическим трендом.
**Validation:** без тренда — die с подсказкой; таблица и --json корректны на фикстуре; `bash packages/analyst/scripts/validate.sh` зелёный.
**Deliverables:** token_report.py + CLI-роутинг + тесты.

### P4.2 — Агент-аналитик + /analyst:deep + ingest

**Status:** ⬜ Not started
**Intent:** Создать `packages/analyst/agents/analyst.md` (opus-tier, read-only tools), команду `/analyst:deep` (digest-first) и `analyst ingest --file F` для findings агента.
**Why:** Скрипты не умеют каузальный нарратив, hidden scope expansion, качество handoff, деградацию cheap-моделей, resolve CONFLICT, тексты remediation — это ниша агента; но сырьё ему давать нельзя (токены + privacy).
**Scope Included:** агент (read-only); deep.md: сначала прогоняет `maind analyze --json` + `token-report --json` + `review --json`, агенту передаются пути к JSON; raw-транскрипты запрещены промптом; ingest: валидация схемы findings → classify_consolidation → только ephemeral-уроки (`detector=agent-finding`) + audit-запись; перегенерация registry (агент/команда попадают в marketplace).
**Scope Excluded:** авто-промоут (человек в гейте — инвариант); harness agent-pack (агент экосистемно-единый, версионируется с CLI); per-session запуск.
**Inputs:** зависит от P3.* (детекторы дают материал) и P4.1 (token-report --json).
**Files:** packages/analyst/agents/analyst.md · packages/analyst/commands/deep.md · packages/analyst/lib/analyst/ingest.py · packages/analyst/lib/analyst/cli.py
**Required Reads:** 1) packages/analyst/lib/analyst/digest.py (classify_consolidation, схема уроков) 2) packages/analyst/lib/analyst/review.py 3) packages/analyst/commands/ (стиль существующих команд) 4) packages/analyst/CLAUDE.md (инварианты)
**Implementation Rules:** ⭐ strong-model (opus) для текстов агента/команды; ingest — sonnet-исполнимо. Агент помечает кандидатов на промоут маркером PROMOTE-CANDIDATE (решает человек).
**Code Guidance:** ingest: невалидный JSON → die БЕЗ каких-либо записей (валидация до первого побочного эффекта); ephemeral-only enforced кодом, не соглашением — попытка иного типа урока = die; audit-запись через существующий механизм провенанса analyst; frontmatter агента — минимальный набор read-only tools, model opus.
**Validation:** ingest пишет только ephemeral; невалидный JSON → die без записи; `skiller registry` перегенерён; `bash packages/analyst/scripts/validate.sh` зелёный.
**Deliverables:** agents/analyst.md + commands/deep.md + ingest.py + тесты.

### P4.3 — analyst proposals + handoff-печать

**Status:** ⬜ Not started
**Intent:** Модуль `proposals.py` + CLI: черновики улучшений (stack-pack/project-override/docs) в `~/.swissknifeman/analyst/proposals/<type>/<id>/` со статусами draft|accepted|rejected и печатью handoff-последовательности.
**Why:** Analyst копит системные предложения, но не имеет права трогать шаблоны/проекты — мост к человеку/plan-design должен быть формальным артефактом.
**Scope Included:** edit-safe writer (как suggest.py: seed_sha256, без timestamp); статусы через audit; печать handoff-последовательности «что и куда применить».
**Scope Excluded:** любая запись в agent-packs/шаблоны/проекты; авто-применение accepted.
**Inputs:** желательно после P4.2 (агент — главный источник предложений).
**Files:** packages/analyst/lib/analyst/proposals.py · packages/analyst/lib/analyst/cli.py
**Required Reads:** 1) packages/analyst/lib/analyst/suggest.py (edit-safe writer паттерн) 2) packages/analyst/lib/analyst/common.py (пути state)
**Implementation Rules:** Каталог — только `~/.swissknifeman/analyst/proposals/`; атомарная запись core.io; детерминизм (seed_sha256, без timestamp в содержимом).
**Code Guidance:** Тест-инвариант «ноль записей вне ~/.swissknifeman/analyst/» — прогон в tmpdir с подменённым HOME и проверкой всего дерева; смена статуса — отдельная audit-строка, не перезапись истории; id предложения — детерминированный слаг от типа+содержимого.
**Validation:** tmpdir-тест на границу записи; `bash packages/analyst/scripts/validate.sh` зелёный.
