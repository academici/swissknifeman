# P7 — ephemeral-дисциплина и закрытие пакета

## Phase Context

Фаза закрывает два хвоста. Первый — висячая ссылка: `roadmap/plan-homes.md` и
`roadmap/changelog-discipline.md` называют «ephemeral-дисциплину» частью этого самого пакета,
но спеки `roadmap/ephemeral-*.md` не существует (repo-grounded: grep 2026-07-10). Владелец
решил (D7): сначала спека по шаблону каталога (проблема · правила · реализация · критерий
внедрения · источник), затем ОТДЕЛЬНОЕ решение — внедрять или отклонить; сам item внедрения
в этот план не входит. Формулировку темы даёт интервью владельца — самовольная реконструкция
смысла «ephemeral» из соседних значений (состояния уроков `analyst`, временные артефакты)
запрещена: это ровно тот класс молча принятого допущения, который протокол называет дефектом.
Второй хвост — честное закрытие пакета: статусы шести пунктов в `roadmap/README.md` приведены
в соответствие факту, корневой CHANGELOG и docs обновлены, план готов к архивации.
Фаза закрыта, когда каталог `roadmap/` не содержит висячих ссылок, а доска плана совпадает
с реальностью репозитория.
