# Codex-субагенты в Claude Code — разгрузка квот и кросс-модельное ревью

**Статус:** roadmap (идея зафиксирована, внедрение по факту потребности; НЕ в скоупе плана
2026.07.18-FOREMAN — чтобы не перегружать)
**Дата:** 2026-07-18
**Источник:** запрос владельца + верификация по GitHub API (Perplexity ложно отрицал
существование репо — доверять только API/README)

## Суть

Официальный плагин OpenAI [`openai/codex-plugin-cc`](https://github.com/openai/codex-plugin-cc)
(29.2k★, Apache-2.0, активен) встраивает Codex в Claude Code:

- `/codex:review` — read-only ревью текущей работы силами Codex;
- `/codex:adversarial-review` — управляемое челлендж-ревью (второе мнение ДРУГОЙ моделью);
- `/codex:rescue` / `/codex:transfer` / `/codex:status` / `/codex:result` / `/codex:cancel` —
  делегация задач, hand-off сессий, фоновые job'ы; субагент `codex:codex-rescue`.
- Установка: `/plugin marketplace add openai/codex-plugin-cc` → `/plugin install codex@openai-codex`
  → `/codex:setup`. Требует Node ≥18.18 + подписку ChatGPT (вкл. Free) или OpenAI API key.
- Биллинг: расходуются лимиты **Codex/OpenAI**, не Claude.

## Зачем нам (оценка выгодности)

1. **Разгрузка квот Claude Max** — прямой ответ на болевой кейс FOREMAN D18 (2–3 учётки Max 20x,
   исчерпание за 2–3 дня): review-стадии и фоновые вспомогательные задачи уходят на отдельную
   учётку OpenAI → длинные прогоны живут дольше без смены учётки.
2. **Кросс-модельное adversarial-ревью** — систематически другая модель ловит другие классы
   ошибок; дешёвое усиление наших review-гейтов (task:review, dev-slice review) без расхода
   Claude-токенов.
3. **Фолбэк-канал при quota-паузе**: когда Claude-лимит исчерпан (weekly), часть очереди
   Foreman теоретически может продолжаться Codex-делегацией вместо полной остановки.

## Ограничения и риски

- Вторая подписка/биллинг; экономика зависит от тарифов Codex (замерить фактическую стоимость
  review-задачи vs Claude).
- Координация двух CLI: конфликты tool-use при параллельных сессиях, свой формат результатов.
- Качество Codex на наших стеках (Laravel/PHP, Dart/Flutter) не замерено — нужен бенчмарк
  до доверия ревью-вердиктам.
- Наши скиллы/хуки/CLAUDE.md Codex не видит — делегировать только самодостаточные задачи
  (ревью диффа, изолированные подзадачи), не plan-protocol-исполнение.

## Гейт внедрения (когда возвращаться к этой записи)

1. FOREMAN дошёл до пилота (P6.3) И quota-паузы реально случаются чаще N раз/нед — тогда
