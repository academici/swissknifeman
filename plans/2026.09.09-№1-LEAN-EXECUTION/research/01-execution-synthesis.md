# Execution synthesis

The twenty-three actionable roadmap carriers collapse into six vertical milestones. P1 removes
avoidable read/dispatch/session restarts. P2 makes bounded repair, producer readiness, re-entry and
archive continuation executable. P3 makes phase close proportional and evidence-based. P4 owns the
repository-visible terminal transcript seam without claiming control of an external conversational
transport. P5 closes two narrow cross-package field gaps. P6 then measures and, only if justified,
reduces Codex instruction/skill cost.

Each phase is one integration boundary. Adjacent items share batch context inside a phase and never
cross audit/close. Validation escalates from focused unit/fixture checks to package validators; a
full audit establishes a material phase baseline once. A later audit is delta/gate-rebind unless
scope, SHA or risk changes materially. There is no separate aggregate P7: P6.4 owns final package,
generator, docs and release-readiness checks, avoiding a paperwork-only phase.
