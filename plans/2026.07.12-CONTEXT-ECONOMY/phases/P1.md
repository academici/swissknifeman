# P1 — maind: тощий старт сессии (digest-бюджет + тихий health)

## Phase Context

maind инжектит в КАЖДУЮ сессию каждого онбордженного проекта (~17) два SessionStart-блока:
дайджест памяти (`maind memory digest`) и статус health. Дайджест ограничен 8 записями, но
не байтами — записи-«простыни» раздули его до ~2.6K ток, плюс через общие ns-scope течёт
чужой контекст (факт vaulter в agelto). Health печатает блок даже когда всё ОК. Фаза вводит
байт/итем-бюджет и делает digest **project-only по умолчанию** (D10, супersede D5:
shared-факты ns/global — ТОЛЬКО по прямому запросу `maind memory recall`/флагу
`--shared-max N`; сами namespaces остаются — для recall и графа), health-хук — тихим при OK.
Завершение:
оба шаблона хуков обновлены (byte-change → stale для sync), новые тесты зелёные,
`validate.sh` maind зелёный. Rollout на проекты — НЕ здесь (P6.2).
