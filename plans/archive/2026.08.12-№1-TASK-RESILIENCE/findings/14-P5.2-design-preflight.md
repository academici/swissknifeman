## Current owner surfaces

- `task.plan_gates.phase_candidate_fingerprint()` binds phase/scope/material risks, terminal item
  spec/state hashes, declared Files and their product-tree digest. Repository HEAD is observation
  metadata and does not enter the digest.
- `phase_audit_policy()` derives audit vs close from complete Routing coverage, Review depth,
  terminal statuses, phase volume and material risk; unresolved input fails toward audit.
- `phase_close_gate()` binds the supplied snapshot to the candidate fingerprint and accepts direct
  low-risk close, the latest same-fingerprint GREEN phase audit, or a strictly validated owner
  decision. Missing/stale/ATTENTION/RED/invalid evidence returns named refusal without phase mutation.
- `plan_closure.build_closure()` materializes the phase closure view only after the phase is
  terminal; the command-layer close gate must already have allowed the transition.

All findings are RAG:— repo-grounded from the commands/files named above; no external fact class is
load-bearing for the P5.2 design verdict.
