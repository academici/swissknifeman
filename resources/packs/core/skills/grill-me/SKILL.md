# Grill Me

Use the current proposal, repository, and prior decisions to identify the
highest-impact open decision. Inspect available sources before asking a question
that the code or documentation can answer.

Ask one decision at a time. Explain the tradeoff and include a recommendation
when the evidence supports one. Follow the user's answers into dependent
decisions, skipping branches that have already been resolved. Confirm terms,
constraints, edge cases, and observable acceptance criteria.

Summarize confirmed decisions and their rationale in the user's terminology.
Record any open decisions with their impact and who can resolve them. Carry
those decisions into the specification when the user requests it.
