# Provider harness contract

**Version:** v0.1.0-draft  
**Status:** draft; sealing owner-gated in P5.1

Контракт должен определить stable harness profile/surface IDs, security intent,
provider-native projections, target scopes/precedence, managed ownership, support states,
provenance/lock, diagnostics и compatibility для settings, permissions/trust,
hooks/context, MCP, agents и agent packs.

До terminal/frozen P0–P4 entry gate и исполнения P5.1 файл фиксирует только назначение.
Он не разрешает package implementation, не делает full access default'ом и не снимает
FOREMAN/fleet no-write gates.
