# orch: заметки сессии P9 (автопилот, батч, остановка)

Дата: 2026-10-25. Модуль-владелец: orch. Статус: наблюдения, кода не менялось (кроме пункта 5).

1. **Нет команды `orch conduct stop`.** Остановить live run можно только сигналом процессу (порядок SIGINT → 60 с → SIGTERM, правило в autopilot-prompt.txt); нужна команда с проверкой lease.
2. **`claude observe --follow` отдаёт историю старого run**, а не следует за текущим: монитор по нему даёт ложные события предыдущего run.
3. **Ложный stage-report исполнителя при незавершённом run:** отчёт стадии читается как итог, пока run не закончен; status должен опираться на `run.end`/lease.
4. **OUTSIDE_SCOPE при коммитах:** коммит conductor-а ловит пути вне `task_files` (D38: `configs/config-inventory.json`), хотя это сопутствующая генерация; нужна категория «сопутствующие пути».
5. **Решено:** `--batch` с `session.executor: handoff` не давал общего контекста, а `flows.md` описывал `shared`. Умолчание теперь `shared` (коммит f7344e4c6); `handoff` и `per-item` остаются настройкой.
6. **Пункт run `blocked: PRE_EXISTING_RED` при `done_with_deviations` в плане:** status run и план расходятся, когда пункт закрыт разбором вне conductor; автопилот не имеет строки для PRE_EXISTING_RED.
