**Intent:** Freeze and implement `provider-health-v1`, composing package-owned desired/status, capability, trust, settings, dependency, budget, locale and mAInd evidence into deterministic project and fleet verdicts without treating provider outputs as intent. RAG:— (repo-grounded: P1/P3 contracts, D5/D15/D20 and `research/06-p6-health-parity-design.md`)
**Why:** Current `maind health`, `maind projects status`, `maind doctor --provider-trust`, Harness provider audit and Skiller status each cover a different axis; no public exact-set gate proves selected-provider capability health or prevents a green subset from masking missing evidence. RAG:— (repo-grounded: `findings/10-p6-health-control-recon-2026-08-02.md`)
**Scope Included:** Frozen composition schema and stable diagnostics; pure aggregate over complete project/provider/axis rows; desired support versus observed activation/readback rules; machine-readable Skiller dependency-closure status; public provider-specific Harness settings audit; mAInd `projects health` orchestration using worktree-local package CLIs and P3/P4 status; exact project-set input; deterministic redaction and compatibility tests.
