**Intent:** Implement an event-sourced scheduler that selects only dependency-ready legal slices, durably brackets the activity boundary, enforces write ownership/budgets/circuit breakers, maps repeated-finding exhaustion through D70's frozen transition and never dispatches a real provider in P2. RAG:— (repo-grounded: D3/D8–D13/D22/D35/D70 and `research/08-p2-prototype-design.md`; `research/16-p2.4-circuit-breaker-reconciliation.md`).

RAG:— (repo-grounded: D10–D11/D22/D70 and P1 contract graph).

**Implementation Rules:** State derives only from strict replay; selection is deterministic over frozen IDs/dependencies; every activity has durable intent first and stable idempotency key; success envelope is only an observation; acceptance requires all frozen deterministic gates. At `READY`, a P2.3 decision with `allowed=false` and reason `RETRY_BUDGET_EXHAUSTED` appends exactly the existing `budget_exhausted` event to `BUDGET_EXHAUSTED`, with the triggering slice/attempt/idempotency identity and exact closed decision as minimized evidence; it appends no intent and calls no activity. That run state is the v1 global admission breaker until explicit owner continue/abort. A cap observed after a boundary follows the legal observation/non-acceptance/reconcile path and trips `budget_exhausted` only after replay legally returns to `READY`. Default activity port refuses `provider_unavailable` before dispatch. Unknown/third state/source drift/failed rollback remains OWNER/incident and is never relabelled as budget exhaustion. RAG:— (repo-grounded: D3/D8–D13/D22/D35/D70 and the frozen transition/authority case banks).
**Code Guidance:** Model scheduler transitions as pure decisions plus explicit store appends; inject time/activity/validation in tests, never read ambient environment. Apply anti-self-deception: positive accepted path, duplicate delivery, crash-resume, no-effect, exact postimage, third state, timeout/quota/schema failure and every budget edge must be independently asserted. For D70, assert the exact frozen authority decision and exact frozen state cell separately; a green final state alone is insufficient. No `while True`, implicit retry, plan-file write, provider name/argv, derived-only breaker flag or invented `circuit_breaker`/`repeated_finding` event is allowed. If any required observed state cannot be expressed by the frozen cells, stop and escalate against D70; never edit P1 artifacts or add a default in P2.4.
