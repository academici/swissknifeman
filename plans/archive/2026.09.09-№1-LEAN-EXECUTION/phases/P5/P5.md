# P5 — Narrow cross-package field gaps

## Phase Context

P5 closes three promoted field gaps through bounded evidence contracts rather than fleet-wide
mutation. P5.1 joins Skiller's existing description-trigger ratchet to the existing budget and
usage audit so authors receive a deterministic debt queue with explicit signal quality; it does
not treat zero observed calls as proof of low value and does not bulk-rewrite canonical skills.
P5.2 adds an Analyst read-only workflow inventory over registered local and vault roots, statically
extracts test/review/verify structure, deduplicates mirrored copies by digest, and compares the
result with the four canonical Task templates. Only an uncovered slot or guard repeated in at
least three distinct plans may update an existing template; new template families and mandatory
stage-matrix changes remain report-only proposals. P5.3 updates the Laravel test-isolation skill
with exact lifecycle-aware parallel DB/filesystem guards and keeps framework-specific policy out
of Task. Cross-project sources are never executed or written. RAG:— (repo-grounded:
`findings/06-p5-design-baseline.md`; `research/06-p5-field-gaps.md`; D10; D1).

**Scope Included:** description-trigger debt membership/priority/evidence fields and filtered audit
view; static workflow discovery/extraction/deduplication; local/vault/archive plan roots; template
coverage and Rule-of-Three verdicts; privacy-safe plan-owned report; conditional existing-template
slot/guard refinement; exact Laravel parallel DB/filesystem isolation guidance and fixtures;
focused package/docs/registry validation.
**Scope Excluded:** bulk edits of the 61 skill descriptions; claims that zero calls mean unused or
misrouted; running untrusted JavaScript; recursive arbitrary-vault crawling; writes to registered
projects or vaults; automatic skill/lesson promotion; a fifth Task template or mandatory workflow
matrix change without a later decision; Task lifecycle work owned by P1–P4.
Laravel-specific policy in Task; suffix/regex proof of parallel DB identity; consumer rollout.
