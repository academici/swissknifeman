# Contributing

Спасибо за вклад в **mAInd**. Пакет держится на нескольких жёстких конвенциях — следуйте им.

## Окружение

- **Python 3.8+** (ядро), **bash** (лаунчер/скрипты), **Node** — только для демона памяти.
- Установка для разработки: `./install.sh`, затем `maind doctor`.

## Запуск

```bash
scripts/test.sh          # unittest, без сторонних зависимостей и без живого демона
scripts/test.sh -v       # подробный вывод
scripts/validate.sh      # py_compile + bash -n + JSON + тесты (то, что гоняет CI)
```

## Конвенции кода

- **Только stdlib в рантайме.** Никаких сторонних Python-зависимостей в `lib/maind/`.
  `networkx`/`graphify` подключаются лениво и только если выбраны через `graph.adapter`.
- **Контекст через `Env`** (`common.Env`, frozen dataclass) — передавайте явно, без
  модульных глобалей. Все пути к состоянию — свойства `Env`.
- **Команды** — функции `cmd_X(env, argv)`, значения словаря `COMMANDS` в `cli.py`.
  Разбор аргументов — `common.parse_args` (флаги + позиционные), не argparse.
- **Атомарная запись JSON** — `common.atomic_write_json` (tmp + `os.replace`). У каждого
  файла-хранилища один писатель.
- **Сообщения и докстринги — на русском.** Ошибки через `die`, предупреждения через `warn`.
- **Память — это внешний Node-демон.** maind его оркестрирует, а не переписывает; тесты
  никогда не требуют живого демона (используйте `tests.fixtures.FakeMemoryServer`).
- **Порты не хардкодим** — `memory.resolve_ports` (env → конфиг → дефолт).

## Тесты

- Стиль — `unittest`; фикстуры в `tests/fixtures.py` (`make_repo` даёт изолированный `Env`
  с временным HOME). Каждый новый модуль `lib/maind/X.py` сопровождается `tests/test_X.py`.
- Тесты не трогают настоящий узел/демон/`~/.maind` — всё во временных каталогах.

## Pull Request

- Перед PR: `scripts/validate.sh` должен быть зелёным.
- Обновите `CHANGELOG.md` (секция `[Unreleased]`).
- Не коммитьте `config.json`, `.env`, `data/*` — они gitignored (машинно-специфичны).
