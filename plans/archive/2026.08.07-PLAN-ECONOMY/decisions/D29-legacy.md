## Решение

**Машинная часть каждого контракта фазы — ОТДЕЛЬНЫЙ JSON рядом с документом** (`<name>-v1.*.json`); документ на неё ссылается и её содержимое НЕ повторяет. P2 поднимает JSON в `packages/task/configs/` дословно и заводит тест равенства — расхождение контракта и конфига становится красным, а не бесшумным.

## Почему

Контракт, чья машинная часть пересказана прозой, порождает два носителя одного факта — ровно тот дефект, который этот план чинит (D25 о пути, D12 об истории). Отдельный JSON делает предикаты фазы проверяемыми УЖЕ в P1 (Validation каждого item'а — не грепы по прозе, а разбор объявления), а не откладывает проверяемость до линтера P3.
