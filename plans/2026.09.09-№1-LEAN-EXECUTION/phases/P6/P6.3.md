### P6.3 — Evidence-gated retain/change decision

**Intent:** Run the matched native evaluation, reduce it through D11, and admit either no change or one minimal provider-delivery candidate without weakening shared semantics. RAG:✅ 2026-09-09 — official OpenAI instruction/skill/non-interactive surfaces (`findings/08-finish-external-verification.md`), confidence high; RAG:— (repo-grounded: D3, D4 and D11) for the measured verdict and repository mutation boundary.
**Why:** The measured baseline shows listing pressure and duplicated delivery candidates, but neither proves that removal improves effective input or preserves behavior. A fixed reducer and one-candidate ceiling keep this phase an evaluation rather than an open-ended context-tuning project. RAG:— (repo-grounded: `findings/07-p6-design-baseline.md`; D3 and D11).
**Scope Included:** three matched repetitions of baseline and one candidate maximum; conditional expansion to five repetitions only for a borderline valid result; mandatory/optional/restart/token/wall-time comparison; robust median/MAD calculation; `retain`, `change` or `insufficient` verdict; D12 execution decision; minimal canonical provider filter/metadata change only after `change`; regenerated projections and before/after source digests.
**Scope Excluded:** multiple-candidate search; removing canonical shared meaning; hand-editing generated files; accepting a token win with any mandatory invariant failure; treating invalid observations as passes; changing provider-neutral behavior for a Codex-only result; rollout outside this repository; release/tag/push.

**Implementation Rules:** Declare and digest the sole candidate before candidate runs. Its spec must freeze the exact Harness `source path → target path` subset or Skiller `identity → canonical → provider target` subset from the two declared manifests before the first canonical mutation; any path absent from that frozen subset is outside Files. Prefer eliminating duplicated provider delivery or disabling unnecessary implicit invocation metadata over deleting semantic content. Run three repetitions for every matched case/arm under the same routed model, effort, cwd family and interleaved schedule. Expand both matched sides to five only when all observations are valid and the three-run effective-input result falls within 10% of either acceptance threshold; do not expand to rescue a failed invariant. Apply D11 mechanically. `change` requires every mandatory invariant in every valid run, zero extra restarts, no optional-quality regression, acceptable wall time and an effective input gain of at least 1,000 tokens or 10% of baseline. Any unknown load source, invalid required observation or unresolved tie is `insufficient`/`retain`, not permission to mutate. Record D12 for exactly one reducer outcome even when the verdict is `retain` or `insufficient`: D12 is executor-authored deterministic evidence, not owner approval. Only D12=`change` backed by complete valid D11 evidence admits the already declared canonical mutation; D12=`retain`/`insufficient` admits none. If changed, edit only frozen canonical owner inputs and regenerate only through `harness instructions` or `skiller registry`; never edit a manifest-selected target directly. RAG:— (repo-grounded: D3, D4 and D11; `research/07-p6-codex-economy.md`).
**Code Guidance:** Keep candidate-spec, raw events, normalized comparison, verdict and decision as separate carriers. Compute `effective_input_gain = baseline_median - candidate_median - max(baseline_MAD, candidate_MAD)` from matched valid samples; record both absolute and baseline-relative values. Compare optional quality as a declared case-level vector, not one averaged score that can hide a regression. Capture before/after digests and generated-file provenance. Stop after the first valid verdict; additional curiosity becomes roadmap evidence.
**Validation:** Evaluator validates frozen digests before launch; every scheduled run is valid or verdict is explicitly `insufficient`; three repetitions exist per matched side, with five only under the documented borderline trigger; independent recomputation from JSONL exactly matches `verdict.json`; mandatory invariant rate is 100% for `change`; extra restart delta is zero; optional vector has no regression; token and wall-time gates report median and MAD; D12 cites artifact and frozen-manifest-subset digests and selects exactly one of retain/change/insufficient; retain leaves canonical/generated product files byte-identical; change's `git diff --name-only` is a subset of the frozen canonical/target set plus the five exact plan evidence carriers and conditional `CHANGELOG.md`, with no separately maintained Codex profile.
**Deliverables:** Complete native matched comparison; deterministic machine verdict; D12 with evidence digests; either an evidence-backed no-change result or one minimal regenerated provider-delivery change.
