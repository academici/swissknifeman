# P0 — Evidence, vocabulary и запечатанные provider contracts

## Phase Context

P0 превращает bootstrap-аудит в утверждённый provider contract до изменений package runtime.
Фаза последовательно пересчитывает inventory, фиксирует ubiquitous language, запечатывает
capability/artifact contracts и формализует migration gates. P0 не реализует adapters и не
снимает паузу с FOREMAN: она только создаёт вход, на котором безопасно детализировать P1–P7.

**Scope Included:** воспроизводимый inventory swissknifeman; capability vocabulary и domain
scenarios; два frozen provider contract и ADR; migration/FOREMAN/fleet gate contract;
P0.6 clean-tree evidence repair с отдельно авторизуемым journal-exception prerequisite;
P0.7 contract-neutral ATTENTION bookkeeping repair; decision/provenance updates внутри
этого плана и `docs/reference.md`.

**Scope Excluded:** любые изменения runtime-кода `core`/packages, кроме exact-scope
owner-approved prerequisite P0.6 в `task`/plan-protocol; генерация Claude/Codex artifacts;
редактирование consumer projects; исполнение FOREMAN; fleet rollout; выбор конкретных P1/P2
class/module layouts до утверждения contracts.

> **Контракт фазы (contract-first).** Потребляет: brief, repo baseline, current first-party capability facts, upstream audit, RED/ATTENTION-аудиты P0 · Производит: sealed capability/artifact/migration-gate contracts, glossary/scenarios, ADR, clean committed evidence и D65 reconciliation manifest · Границы: package runtime не меняется вне отдельно owner-approved P0.6 prerequisite; provider outputs, main, FOREMAN и fleet projects не меняются.
