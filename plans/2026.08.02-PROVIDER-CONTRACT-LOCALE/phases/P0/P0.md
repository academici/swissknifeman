# P0 — Evidence, safety, and full fleet inventory

## Phase Context

P0 создаёт воспроизводимую точку отсчёта до новых control-plane, Skill Core и locale контрактов.
Фаза отделяет committed HEAD от dirty worktree, проверяет каждую зарегистрированную
точку флота и не считает успех одного provider здоровьем пары. P0.1–P0.4 остаются
неизменяемой terminal history; RED-аудит F1–F7 реопенил фазу через forward-fix цепочку
P0.5→P0.6→P0.7→P0.8 (D64–D66), не переписывая их specs, commits или journal rows.
Все items последовательны: P0.5 перепроизводит baseline, P0.6 — recovery contract/checker,
P0.7 — fresh security evidence, P0.8 — provenance/fan-in; criterion orchestration не срабатывает.

**Scope Included:** пофайловый read-only inventory всех записей флота; per-provider health/trust/budget evidence;
текущий skill/bucket/source-publication inventory, 90-day usage/residency/audit signals, both-provider
profile listing outcomes and measurement uncertainty; классификация каждого provider-relevant path;
recovery/admission contract; только owner-approved
срочное credential/trust containment с backup, rollback и protected-delta evidence; audit-driven exact-set,
semantic-checker, executable-security-producer and append-only provenance remediation.

**Scope Excluded:** control-plane/locale implementation; bulk skill or documentation rewrite; удаление legacy assets;
обычная Brain/fleet migration; запись секретов, абсолютных consumer-root paths или содержимого
чужих локальных overrides в артефакты плана.

> **Контракт фазы (contract-first).** Потребляет: brief/00–03, findings/01–03, findings/13 and P0 audit F1–F7, current configs/registry/audit tools, registered fleet and frozen `2026.07.19-DUAL-PROVIDER` contracts · Производит: sealed exact redacted fleet/skill baseline, exact migration classifications, acyclic semantic recovery gates, executable security evidence and append-only execution provenance · Границы: no package/control-plane implementation, corpus rewrite/merge, bulk fleet mutation, cleanup, historical rewrite or unapproved credential action.
