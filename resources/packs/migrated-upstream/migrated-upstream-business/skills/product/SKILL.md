# Product Management Super-Skill (navigator)

Thin navigator over the full external reference in `references/full.md` (~79KB,
upstream `get-zeked/pm-super-skill`): an end-to-end PM handbook merging Perplexity
Computer's six PM skills with the Claude Code product team toolkit — templates,
frameworks, and checklists across the whole PM workflow.

**Routing first.** For a specific task prefer the granular native pm/ skill
(deeper, conflict-free): `brd` · `prd-from-brd` · `product-roadmap` ·
`requirement-critic` · `unit-economics` · `monetization-design` · `go-to-market` ·
`pmf-diagnostics` · `business-process`. Open this reference only for a
cross-cutting overview or a topic no single skill covers (sprint/agile mechanics,
user research, UI design systems, competitive analysis, stakeholder comms).

**Usage rule:** do NOT load `references/full.md` whole. Identify the section for
the concrete question below, then read only that section (grep the heading or
jump by anchor).
