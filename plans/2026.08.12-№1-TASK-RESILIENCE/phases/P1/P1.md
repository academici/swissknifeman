# P1 — Active-plan migration and Layout v1 execution retirement

## Phase Context

P1 выполняет one-way cutover: сначала строит inventory всех active plan roots в umbrella и
зарегистрированных skiller/maind проектах, затем мигрирует каждый Layout v1 с lossless evidence,
после чего удаляет из Task именно execution layout v1. Архивные v1 остаются inert Git bytes;
unrelated contracts со schema version `v1` не входят в это удаление. RAG:✅ 2026-08-12
(Perplexity Web + Microsoft Durable Functions version retirement; findings/02).

**Scope Included:** repository + registered fleet inventory, safe v1→v2 conversion, generated carriers, v2-only layout resolver/lint/read path/commands/docs/tests.

**Scope Excluded:** переписывание archived v1 history; удаление `task-contract/v1`, receipt/v1 или других не-layout контрактов; unregistered filesystem scanning.

> **Контракт фазы (contract-first).** Потребляет: P0 acceptance/RAG · Производит: zero-active-v1 proof + v2-only Task runtime · Границы: migration before reader removal.
