# P6.2 recovery design — tracked-tree fingerprint and v0.13.1

RAG:— (repo-grounded).

## Evidence chain

- Layer 1 audit evidence: `findings/22-P6-audit-2026-08-13.md` proves that
  `packages/harness/tests/**` is recorded as `state=missing`, while changing bytes beneath that
  declaration can leave the phase candidate unchanged.
- Runtime source: `packages/task/lib/task/plan_gates.py` resolves every declaration as a literal
  `Path` and recursively reads directories from the worktree, including ignored files.
- Focused tests: `packages/task/tests/test_plan_gates.py` cover exact plan/repository-relative files
  but not directories, globs, brace sets, ignored members or tracked deletions.
- Historical release boundary: `artifacts/P6/verified-tag-v1.json` binds the immutable annotated
  `v0.13.0` tag to `3c5548f7d15100e3b992e62e08f7e8ef2a92b0d0`.
- Release policy: `packages/skiller/skills/repository-bootstrap/release-discipline/SKILL.md` assigns
  fixes to a patch release, requires a root CHANGELOG cut and keeps tag push manual.

## Alternatives

1. Replace the wildcard with the literal `packages/harness/tests` directory. Rejected: the current
   recursive worktree walk includes ignored runtime bytes such as `__pycache__`, so two equivalent
   clean checkouts can produce different fingerprints.
2. Accept the known `v0.13.0` gap. Rejected by the repository owner through DecisionRequest
   `P6-audit-frozen-release-boundary-2026-08-13`.
3. Move or overwrite `v0.13.0`. Rejected: it destroys already-consumed P6.3/P6.4 evidence.
4. Resolve Files declarations against Git's tracked set and issue `v0.13.1`. Selected: this binds
   exact files, directories, `**` globs and bounded brace alternatives to deterministic repository
   members while excluding ignored/untracked cache bytes.

## Target contract

- Enumerate members with `git ls-files -z --cached -- <pathspecs>` from the repository root.
- Preserve exact literal and directory behavior; convert wildcard declarations to Git `:(glob)`
  pathspecs and expand non-nested brace alternatives deterministically with a strict expansion cap.
- Normalize to unique sorted repo-relative POSIX paths before hashing.
- Hash current worktree bytes of tracked regular files, retain explicit symlink/deleted states, and
  fail closed on Git/pathspec/escape errors. Ignored and untracked members never enter a directory
  or glob row.
- Regression acceptance proves: directory and recursive glob select the same tracked members;
  brace sets select every alternative; tracked edits/deletions change the fingerprint; ignored and
  untracked cache files do not.
- Bump Task plugin release sources and generated provider artifacts to `0.13.1`, cut the single root
  CHANGELOG, run the full release gates on the exact committed candidate, and create a new local
  annotated `v0.13.1`. `v0.13.0`, its tag object and all P6.3/P6.4 evidence remain byte-unchanged.
- No registered-project update is required by this item: Task plugin consumers resolve committed
  repository SHAs, tags are human markers, and the selected owner action explicitly preserves the
  completed P6.4 evidence. Push and GitHub release remain unauthorized.
