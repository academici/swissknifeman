# P0 — Evidence, vocabulary и запечатанные provider contracts

## Phase Context

P0 превращает bootstrap-аудит в утверждённый provider contract до изменений package runtime.
Фаза последовательно пересчитывает inventory, фиксирует ubiquitous language, запечатывает
capability/artifact contracts и формализует migration gates. P0 не реализует adapters и не
снимает паузу с FOREMAN: она только создаёт вход, на котором безопасно детализировать P1–P7.

**Scope Included:** воспроизводимый inventory swissknifeman; capability vocabulary и domain
scenarios; два frozen provider contract и ADR; migration/FOREMAN/fleet gate contract;
decision/provenance updates внутри этого плана и `docs/reference.md`.

**Scope Excluded:** изменения runtime-кода `core`/packages; генерация Claude/Codex artifacts;
редактирование consumer projects; исполнение FOREMAN; fleet rollout; выбор конкретных P1/P2
class/module layouts до утверждения contracts.

> **Контракт фазы (contract-first).** Потребляет: brief, repo baseline, current first-party capability facts, upstream audit · Производит: sealed capability/artifact/migration-gate contracts, glossary/scenarios и ADR · Границы: не меняет package runtime, provider outputs, FOREMAN или fleet projects.
