# plan-guard

`PreToolUse` hook for `Edit|Write|MultiEdit`. A planner plan directory (the one holding `plan.json`) keeps its JSON as
the only source of truth; `index.md`, `plan.md`, `roadmap.md`, `status.md`, `handoff.md`, `open-questions.md`,
`AGENTS.md`, `CLAUDE.md`, everything under `context/` and `phases/*/*/U*/brief.md` are generated by `plan.py`.

- `strict` blocks the edit with `generated by plan.py — change JSON through plan.py`; `warn` only prints it.
- A directory without `plan.json` is not guarded.
- Enable per project: `harness hooks --target . --plan-guard strict`; kill-switch `MODE=off` in
  `.claude/plan-guard.env.ini`.
