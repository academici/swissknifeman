# P1 — Minimal runtime alignment and field canary

## Phase Context

Фаза переносит Skiller-owned semantics в Task commands/runtime, реализует D12 evidence-first
classification и D13 idempotent/correlated lifecycle, затем применяет результат к живой работе.
P1.1 исполнен из `packages/task` и закрыт с deviation на отсутствовавший plan-owned read-budget;
D15 materializes frozen v1.1.0 без reopen или расширения sealed P1.1 Files. P1.2 работает из
repository root, читает contract через digest-qualified bundle и не пишет package code. Итоговый
verdict объединяет focused checks с фактической траекторией и bounded replay реальных случаев
Agelto/Swiss Knife Man.

**Scope Included:** Task plan-команды, D12 signal/action classifier, safe fallbacks, process/delta/
future-carrier semantics, layout-v2 context carrier, procedural routing outcome, D13 session/run
correlation and idempotent close, D14 pre-close audit gate and recovery-only item reconciliation,
material review trigger/reuse, frozen read-budget v1.1.0 admission, canonical Task docs + standalone/
aggregate builds, focused tests, factual `[Unreleased]` ledger до D9, committed external-ledger
prerequisite и field canary с exact no-event/stop-tax outcomes.

**Scope Excluded:** универсальный supervisor, migration/archive rewrite, exhaustive model eval,
новая телеметрическая платформа и исправление несвязанных проблем canary-проектов.

> **Контракт фазы (contract-first).** Потребляет: terminal P0 semantics, D1–D15 и plan-owned frozen `root/contracts/read-budget-v1.md` · Производит: согласованные Task commands/runtime/docs, evidence-first stop policy, correlated lifecycle, pre-close audit gate, factual root `[Unreleased]` ledger и GO либо ADJUST field verdict · Границы: P1.1 остаётся terminal и не реопенится ради plan carrier; P1.2 пишет только root canary evidence, ждёт единый committed `docs/reference.md` prerequisite D9+D13 и не поглощает его foreign diff; ADJUST остаётся nonterminal owner decision без автоматического design/audit loop.
