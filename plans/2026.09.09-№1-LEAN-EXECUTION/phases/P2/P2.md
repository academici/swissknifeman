# P2 — Bounded repair, readiness, re-entry and archive

## Phase Context

P2 converts three classes of false terminal transition into one bounded continue-first lifecycle.
It first qualifies validation/checkpoint repairs before block or redesign, then makes producer
readiness and terminal-phase re-entry explicit, and finally removes Brain from repo-owned archive.
It consumes P1 admission/continuity and D2/D7 so a safe repair remains in the owning root while
terminal public/security/authority boundaries still fail closed. Completion means the four field
incident families have deterministic fixtures, unjustified design/re-open handoffs are rejected,
producer evidence reaches the consumer bundle, and archive succeeds without Brain availability.

**Scope Included:** repair evidence/reducer, producer readiness, phase re-entry justification, priority-fix dispatch, archive command.
**Scope Excluded:** arbitrary neighbouring cleanup; weakening public/security/authority gates; phase audit evidence reuse (P3).
