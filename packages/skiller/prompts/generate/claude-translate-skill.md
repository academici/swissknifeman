# Claude: перевод SKILL.md → SKILL.&lt;lang&gt;.md

Переведи приложенный `SKILL.md` в человекочитаемый вариант на другом языке.
Файл-перевод (`SKILL.<lang>.md`, напр. `SKILL.en.md`) **gitignored и не грузится
агентом** — это справка для человека рядом с каноном `SKILL.md`.

## Правила
1. В начало добавь строку-маркер:
   `> 🌐 Перевод для человека. Агент использует SKILL.md, не этот файл.`
2. Переводи свободно с пояснениями, не дословно.
3. Технические термины, пути, команды, имена полей — оставь как есть.
4. Комментарии внутри code-блоков — переведи; сам код не трогай.
5. Frontmatter — скопируй без изменений (источник истины — `SKILL.md`).
6. В конце добавь секцию «Контекст для человека»: 3–5 предложений — зачем скилл,
   когда реально применяется, с чем связан.

Выведи только содержимое `SKILL.<lang>.md` + строку с путём файла.

> миграции канона в компактный английский. Покрытие переводов:
