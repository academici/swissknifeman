# P6 — ecosystem-glossary: единый язык трёхслойкой

## Phase Context

Фаза внедряет единый язык экосистемы БЕЗ мега-глоссария (спека `roadmap/ecosystem-glossary.md`,
тезисы RAG-подтверждены 2026-07-10: документированные failure modes центральных глоссариев —
протухание, выхолащивание терминов, отсутствие владельца, semantic drift).
Трёхслойка. Слой 1 — стилистика кода как механика, не документ: идиомы каждого языка (PHP/Dart/
Python) НЕ выравниваются, форматтеры/линтеры per язык обязательны в CI; кросс-языковое — только
дисциплина «имя раскрывает намерение» (`naming-conventions`) и стиль докстрингов (`writing-style`).
Слой 2 — домен per пакет в `CONTEXT.md` (канон `architect/domain-modeling` уже предписывает
inline-запись терминов): усиливается триггерами обновления и пунктом «Glossary impact?» в
ревью-чеклистах. Слой 3 — тонкий term-index в Brain `02-Knowledge/00-Strategy/` (Rule of Two:
только термины, пересёкшие границу 2+ пакетов; формат «термин → пакет-владелец → коллизии →
deprecated-синонимы»). Раскладка «механизм в SKM, содержимое в Brain» — по шаблону радара.
Ревьюер — СУЩЕСТВУЮЩИЙ: это дополнительное измерение conformance-finder'а Stage B в `task:review`,
новый агент/пак не заводится. Новая линковка Brain↔проекты не нужна.
Наполнение term-index тайм-гейтовое (после dev-волны ECOSYSTEM P4) — вынесено отдельным item'ом.

> СКЕЛЕТ — не детализирован, разворачивается /task:plan-design SKM-ROADMAP-005 P6
