### P5.1 — Enforce byte-bound terminal delivery receipts

**Intent:** Проверить/довести receipt builder/CLI, который отказывает nonterminal subject, сверяет terminal journal/state/result/run ID, bind'ит carrier digests/commit и возвращает exact persisted recommendation/Next. RAG:— (repo-grounded: terminal continuity roadmap + D5).
**Why:** Prompt-only правило не мешает агенту закрыть chat до durable state или потерять точную команду продолжения. RAG:— (repo-grounded: findings/00).
**Scope Included:** item/phase/archive terminal receipt; design/audit handoff receipt; stale/missing/mismatch refusal codes; atomic write; CLI; command integration for all five canonical plan commands; tests.
**Scope Excluded:** host transport heartbeat/final hook; synthetic terminal event; Git push; provider generation.
**Inputs:** terminal P4; D5; current candidate implementation.

**Required Reads:** 1) `roadmap/2026.08.11-terminal-final-continuity-receipt.md` 2) `roadmap/2026.08.11-terminal-handoff-recommendation-receipt.md` 3) `decisions/D5-terminal-receipt-boundary.md` 4) `packages/task/lib/task/plan_delivery.py` 5) `packages/task/scripts/plan-delivery.py` 6) `packages/task/tests/test_plan_delivery.py` 7) `packages/task/commands/plan-design.md` 8) `packages/task/commands/plan-exec.md` 9) `packages/task/commands/plan-run.md` 10) `packages/task/commands/plan-audit.md` 11) `packages/task/commands/plan-close.md`
**Implementation Rules:** Receipt never mutates terminal state; source is persisted plan/journal/handoff; nonterminal returns `FINAL_BEFORE_TERMINAL_FORBIDDEN`; mismatch/stale fails; atomic replace; v2-only after P1. RAG:— (repo-grounded: D5/root.evidence-integrity).
**Code Guidance:** Table-test item, phase and archive terminal subjects plus design/audit handoff subjects; vary status/result/run-id/digest/Next independently and assert exact `next_exact`/recommendation bytes. Use the persisted carrier, never chat-derived values; test atomic replacement without leaving a temporary file. Every canonical command calls the appropriate receipt immediately before its terminal response; do not edit generated provider projections here (P5.3 owns them).
