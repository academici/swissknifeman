## 1. `process.py:80` — JSON `\uXXXX` of a surrogateescape secret is returned in the stderr tail

`_char_pattern` skips U+DC80–U+DCFF. The compiled pattern for U+DCFF is only `b'(?:\xff|%[fF][fF])'` and `reach` is 3. `json.dumps` writes a 6-byte `\uXXXX` escape (any hex case). That spelling is what ends up in the default 2 KiB tail, and `json.loads` of the tail restores the secret. The same character’s raw byte and `%FF` form are redacted. On the document path the JSON parser decodes the escape first, and `str.replace` removes it.

```text
reach 3
pattern b'(?:\xff|%[fF][fF])'
lower 'token-\\udcff-SENTINEL' sentinel True
upper 'token-\\uDCFF-SENTINEL' sentinel True
mixed 'token-\\uDcFf-SENTINEL' sentinel True
```

Reproduction:

```bash
PYTHONPATH=packages/aicore/lib python3 - << 'PY'
import os, sys
sys.path.insert(0, "packages/aicore/lib")
from aicore.ext.process import run_json, _char_pattern
secret = "token-\udcff-SENTINEL"
print(_char_pattern("\udcff"))
code = "import os,sys; sys.stderr.buffer.write(os.environ['B'].encode()); sys.stdout.write('{}')"
for blob in (b"token-\\udcff-SENTINEL", b"token-\\uDCFF-SENTINEL", b"token-\\uDcFf-SENTINEL"):
    r = run_json([sys.executable, "-c", code], {}, deadline_s=10, env={"B": blob.decode()}, cwd=None, secrets_to_redact=[secret])
    print(ascii(r.stderr_tail), "SENTINEL" in r.stderr_tail)
PY
```

`json.dumps` of the same secret yields the quoted lowercase form, and `json.loads` of `stderr_tail` compares equal to the secret.

## 2. `process.py:77` and `process.py:130` — `re.sub` of the per-character alternation hangs the host after the child has exited

For `\`, the alternatives include a 1-byte match and a 2-byte `\\` match. On a run of backslash bytes both succeed, so a secret of n backslashes followed by another character is exponential. Redaction runs after the child is reaped, so `deadline_s` does not stop it. A Windows path with separated backslashes, a run of `/`, and a run of `%` stayed under a millisecond.
