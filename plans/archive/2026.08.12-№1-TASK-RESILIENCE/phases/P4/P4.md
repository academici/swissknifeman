# P4 — Confirmed blocking and mandatory external RAG

## Phase Context

P4 превращает первую block hypothesis в закрытый nonterminal capsule. Детерминированный reducer
сначала требует verified Perplexity evidence для external class, затем один fresh distinct-context
isolated reviewer. Reviewer оценивает evidence, но terminal action выбирает только reducer:
`JUSTIFIED` разрешает block, `AVOIDABLE` возвращает repair, `INSUFFICIENT_EVIDENCE` продолжает сбор.
RAG:✅ 2026-08-12 (Perplexity Web recovery/blocked-state synthesis; findings/02).

**Scope Included:** block schema/reducer, `rag-pending`, isolated reviewer rubric, five command integrations, deterministic tests.

**Scope Excluded:** authorization новых side effects; unlimited retry; reviewer self-attestation; fallback-as-Perplexity-success.

> **Контракт фазы (contract-first).** Потребляет: P3 observations + P0 RAG acceptance · Производит: единственный terminal block authority · Границы: reviewer evidence only.
