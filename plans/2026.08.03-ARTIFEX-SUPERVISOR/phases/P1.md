# P1 — Freeze supervisor contracts

## Phase Context

P1 freezes five additive provider-neutral contracts which P2–P6 may implement and measure
without reopening authority, recovery or economic semantics. It is design-ready but execution is
hard-gated on terminal P0: P0 currently has 0/5 terminal items, so none of its planned artifacts
is claimed as present evidence. RAG:— (repo-grounded: `phases/P0.md` and
`research/07-p1-contract-freeze-design.md`).

**Scope Included:** plan-local Markdown contracts, normalized adversarial case banks, stdlib
validators, a `harness run` reuse/gap crosswalk, a cross-contract manifest, and decisions needed
to freeze ownership, failure modes, versioning and consumer boundaries.

**Scope Excluded:** supervisor/provider/package runtime; changes under `packages/**` or `core/**`;
P0 execution/closure; raw provider streams, prompts or secrets; hook repair; release/Brain/mAInd
mutation; package promotion and post-P1 product decisions.

> **Контракт фазы (contract-first).** Потребляет: terminal P0.1–P0.5 outputs after their validators pass (currently planned, not produced) + committed donor contracts named in `plan.md` §7 + live `harness run` gap evidence · Производит: frozen `supervisor-run-v1`, `slice-manifest-v1`, `authority-policy-v1`, `worker-envelope-v1`, `economy-evidence-v1`, per-contract cases/validators and aggregate manifest · Границы: semantics/fixtures/verifiers only; no candidate runtime, donor/archive edits or invented P0/provider values.

Items execute strictly P1.1→P1.5. Grouped execution is inapplicable: every later item consumes
prior deliverables and each frozen public contract requires a manual frontier/high checkpoint;
execution remains item-by-item. RAG:— (repo-grounded:
`research/07-p1-contract-freeze-design.md`).
