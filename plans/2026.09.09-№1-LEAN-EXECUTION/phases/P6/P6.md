# P6 — Measured Codex instruction and skill economy

## Phase Context

P6 turns the Codex context-cost hypothesis into a bounded native experiment. P6.1 freezes the
actual cold-start source inventory and a twelve-case corpus before mutation. P6.2 adds a
deterministic, resumable evaluator around native `codex exec --json`. P6.3 compares one candidate
at most with the untouched baseline and either retains the current behavior or records a measured
provider-delivery change. P6.4 qualifies every affected owner and generated projection. Shared
semantics remain canonical; no static Codex-only profile is introduced. RAG:✅ 2026-09-09 —
official OpenAI AGENTS discovery, skill disclosure/invocation and non-interactive JSONL contracts,
recorded in `findings/01-codex-instruction-baseline.md`, `research/07-p6-codex-economy.md` and
`findings/08-finish-external-verification.md`; confidence high. RAG:— (repo-grounded:
`findings/07-p6-design-baseline.md`; D3, D4 and D11) for repository ownership and experiment policy.

**Scope Included:** native Codex root/package cold-start inventory; fixed positive, explicit and
near-miss evaluation cases; deterministic JSONL capture and reducer; digest-bound resume; one
provider-metadata/filter candidate maximum; retain/change/insufficient verdict; canonical generator,
package, registry and documentation qualification.
**Scope Excluded:** deleting shared semantics before measurement; a separately maintained Codex
profile; testing many candidates; live provider calls in unit tests; treating body bytes as resident
cost; editing generated AGENTS or `.agents/skills/**` directly; external rollout, release or push.

> **Phase Assurance | v1.**
> Impact: internal-integration
> Integration Seams: `codex-cold-start` · `skiller-eval-context` · `harness-instruction-rendering` · `skiller-publication`
> Live or Irreversible: live calls are bounded and read-only; repository edits are reversible
> Audit Intent: required
> Rationale: a provider-native measurement may change always-on delivery across shared generators.

> **Контракт фазы (contract-first).** Потребляет: D3 + D4 + frozen source/case digests · Производит: `codex-context-eval/v1` + D12 retain/change verdict + qualified projections · Границы: mandatory invariants never regress, unknown is insufficient, one candidate maximum, canonical sources only.
