# desc-burndown.txt — рэтчет frontmatter `description` (P3.2)
#
# Формат: одна запись на строку — `<bucket>/<name>` (совпадает с frontmatter bucket:name).
# Строки, начинающиеся с `#`, и пустые — комментарии, игнорируются.
#
# Правила (see validate.sh, секция description-гейтов):
#   - description > DESC_ERROR_MAX (450 симв) — ВСЕГДА hard error, burn-down не спасает.
#   - description > DESC_WARN_MAX (300 симв) и <= 450:
#       * скилл ЕСТЬ в этом списке → warn (легально, унаследованный долг);
#       * скилла НЕТ в списке → error (новый долг запрещён — рэтчет).
#   - Запись «протухла» (скилл удалён/переименован ИЛИ его description уже <= 300 симв) →
#     validate.sh печатает warn «протухшая запись, убери» — удали строку при сокращении.
#
# One-way: список ТОЛЬКО уменьшается. Добавление новых строк вне bootstrap этого item —
# осознанное решение отдельного item'а с обоснованием в его Completion Notes, не тихая правка.
#
# Bootstrap (2026-07-12, P3.2): весь остаток >300 симв после P3.1 (64 скилла,
# см. Completion Notes P3.1).
