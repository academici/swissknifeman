**Intent:** Compile the `Batch` column of `plan.md §3 Routing` into one pre-mutation admission verdict so only an exact declared batch, `solo`, or a durable remaining suffix can start. RAG:— (repo-grounded: artifacts/source-roadmap/2026.08.11-roadmap-batch-selection-is-authoritative.md:60-84; decisions/D6-routing-batch-ssot.md).
**Why:** Current lint can detect a collapsed batch in a later handoff, but `task_contract.build()` resolves only the selected item route, so a direct partial invocation can start before the declared execution unit is checked. RAG:— (repo-grounded: artifacts/source-roadmap/2026.08.11-roadmap-batch-selection-is-authoritative.md:25-58; packages/task/lib/task/task_contract.py:443-515).
