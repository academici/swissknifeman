diagnostic.

## F3 — The seam's prompt therefore cannot state the task

`packages/artifex/lib/artifex/activity.py:_prompt` (P5.5's surface under D119), verbatim:

```python
def _prompt(self) -> str:
    files = ", ".join(self.admission["task"]["files"])
    return ("Work only in these admission-declared files: " + files
            + ". Implement the bounded repository slice, modify no other path, create no "
              "commit, then return only a JSON object satisfying the supplied schema.")
```

Its only input is `admission["task"]["files"]`. Per F1 that object contains no description,
so no prompt wording change inside `_prompt` alone can state the task — **the information is
not present at that call site.** This is a P5.1 carrier-shape gap surfacing as a P5.5 prompt
limitation, not a wording defect.

## F6 — Adding a description field to the admission is a frozen-contract edit

`root/contracts/business-dispatch-admission-v1.md` (frozen `@1.0.0`, P5.5-owned): *"Unknown
fields or versions, a changed hash/index/cardinality, revocation, expiry, changed
provider/root/files/capabilities, replay reuse, G2/G2B substitution, or any nonzero use refuse
before intent."* A new `task.scenario` field is an unknown field → refusal before intent. Adding
it requires editing the frozen contract text, re-minting all 14 admissions (every `task_hash`
changes), re-freezing both G2B manifests, and a fresh owner grant, because the D105 rows bind
the current hashes.
