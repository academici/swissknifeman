# P2 — Deterministic adapters, provenance, lock и drift engine

## Phase Context

P2 создаёт общий stdlib-only artifact kernel, через который P3–P6 смогут строить
provider-native outputs из одного semantic source. Фаза переносит в общий контракт уже
повторившиеся в `skiller`, `harness` и `maind` механизмы: детерминированный render plan,
provenance, lock/hash, managed boundaries, drift classification и fail-closed repair.
Provider-specific преобразования и CLI остаются у owning packages и передаются kernel
явно; import-time registry, filesystem discovery и скрытые глобальные adapters запрещены.
Завершение P2 — общий API плюс synthetic conformance matrix, но без записи в реальные
project/fleet targets и без изменения Claude/Codex delivery behavior.

**Scope Included:** core contribution proposal + ADR; deterministic artifact/render value
types; canonical byte/hash/provenance rules; versioned lock; managed/unmanaged boundary;
pure drift/diagnostic/repair planning; explicit capability-aware adapter catalog; dry-run,
doctor projections и synthetic conformance fixtures.

**Scope Excluded:** semantic renderers для skills/task/harness/mAInd (P3–P6); provider
marketplaces/install/update commands; реальные `.claude`/`.codex` writes; root/fleet config
migration; FOREMAN execution/editing; fleet rollout; dynamic plugin discovery; новый package;
network/subprocess и provider SDK dependencies.

> **Контракт фазы (contract-first).** Потребляет: terminal P1.4, frozen v1.0.0 capability/artifact/config/migration-gate contracts, public P1 provider/resolver API и anchored compatibility matrix · Производит: approved core-contribution proposal/ADR, public artifact/render/lock/registry API и synthetic conformance evidence для P3–P6 · Границы: не реализует package-specific semantics/CLI, не пишет в swissknifeman/FOREMAN/fleet targets и не меняет provider delivery behavior.

**Entry gate:** детализация P2 готова, но P2.1 не начинается, пока P0.3/P0.4 и P1.1–P1.4
не терминальны, все четыре входных contracts не frozen v1.0.0, а Approval Owner D# не
подтверждает общий `core` artifact seam. Draft placeholders задают intent, но не поля API.
RAG:— (repo-grounded: `phases/P1.md`, `root/contracts/provider-{capability,artifact,config}-contract.md`, D12/D16)
