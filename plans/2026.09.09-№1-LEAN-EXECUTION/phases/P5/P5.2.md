### P5.2 — Analyst test-strategy fleet synthesis

**Intent:** Add a deterministic Analyst `workflow-scan` command that statically inventories registered field workflows, synthesizes their test/review/verify strategies against the four canonical Task templates, and permits only report-backed refinements to existing template slots or guards. RAG:— (repo-grounded: `artifacts/source-roadmap/workflow-craft.md`; `packages/analyst/lib/analyst/scan.py`; `packages/task/workflows/README.md`).
**Why:** The roadmap trigger has fired by owner priority and the current registered local/vault reconnaissance contains 55 path occurrences, 40 unique content digests and 38 unique `export const meta` scripts, but Analyst only scans lesson stores. Mirrors, archives, unsupported legacy scripts and template coverage are therefore indistinguishable without ad-hoc shell analysis. RAG:— (repo-grounded: `findings/06-p5-design-baseline.md`; `packages/analyst/lib/analyst/scan.py`).
**Scope Included:** `workflow-fleet-report/v1`; enabled-project discovery from the existing maind `config.json` reader shape; bounded `local_path` and `vault_path` plan roots including active and `plans/archive/<ID>/workflows`; canonical relative source identities; SHA-256 mirror deduplication with aliases retained; static bounded extraction of `export const meta`, stage/type/model/schema and tests-to-green/review/verify/gate/commit/max-iteration/judge-panel features; unsupported/malformed diagnostics; comparison with the four Task templates using the same extractor; coverage, anti-pattern and Rule-of-Three candidate groups; distinct-plan evidence counting; `--project`, `--output`, `--now` and `--json` controls; deterministic JSON/Markdown output to an explicit path; conditional slot/guard refinement in an existing template and docs/provider registry regeneration.
**Scope Excluded:** Executing or importing discovered JavaScript; recursive arbitrary-vault search outside declared plan roots; raw prompts/transcripts/secrets in reports; writes to any registered project or vault; treating mirrored local/vault copies as separate evidence; automatic lesson/skill/template promotion; a fifth template family; changing the design/dev mandatory-stage matrix; provider runtime changes; product workflow execution.

**Implementation Rules:** Analyst remains stdlib-only and read-only over fleet sources. Discover only explicit `<root>/plans/*/workflows/*.js` and `<root>/plans/archive/*/workflows/*.js` under each enabled project's `local_path`/`vault_path`; missing roots are counted, not fatal. Resolve path identities, hash bytes before extraction, collapse exact digest mirrors and retain normalized aliases without committing absolute home paths. Never evaluate JavaScript: a bounded string/comment/brace-aware extractor returns `qualified`, `unsupported` or `malformed`, and every exclusion is counted. Apply the same extractor to canonical templates. A template refinement requires an uncovered feature repeated by at least three distinct plan IDs after digest deduplication and a failing-then-green template comparison fixture; otherwise the report records `covered` or `hold`. A new template family or mandatory-stage-matrix change is report-only and requires a later D-record. `--now` is the sole report timestamp input and makes fixtures byte-reproducible. The command writes only an explicitly requested report path; no foreign tree, lesson store or Task file is mutated by Analyst itself. RAG:— (repo-grounded: D10; Analyst privacy/human-gate and Task workflow ownership).
**Code Guidance:** Separate pure stages: registry normalization → bounded candidate paths → digest/alias inventory → static feature extraction → canonical-template comparison → deterministic synthesis/rendering. Use temp-directory fixtures with local/vault mirrors, archives, duplicate bytes, symlinks escaping a declared root, missing roots, invalid UTF-8, no-meta legacy files, braces inside strings/comments and three distinct-plan candidates. Do not use `node`, regex-execute JavaScript, `eval`, shelling, `rglob()` across a vault, or keyword presence alone as a promotion verdict. A feature detector may be conservative; unknown becomes evidence insufficiency, never absence. Existing templates change only after the generated report names the exact repeated evidence and the focused fixture proves the delta; never add a generic slot for a singleton curiosity.
