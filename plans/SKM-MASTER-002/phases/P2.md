# P2 — Токен-телеметрия end-to-end (фаза B)

## Phase Context

Замыкаем токен-телеметрию: парсер usage уже есть в `packages/skiller/lib/skiller/analyze.py`,
но изолирован; run-report (SCHEMA=1) usage не извлекает — главный gap. Строим единый
транскрипт-парсер `core/usage.py` (stdlib, self-contained) и поднимаем хук run-report до
SCHEMA=2 — only-additive: блок `usage{totals,by_model,agents[],cache_hit,…}` + `reads` +
`error_loops` + `retrieval` + `protected_writes`; субагенты — из sidecar
`<sid>/subagents/agent-*.jsonl` (cap 50). USD не считаем (D6) — сырые токены model-keyed.
Вендоринг в хук: копия `_usage.py` + sync-скрипт + cmp-гейт в validate + doctor-проверка (D8);
хук никогда не падает (`usage=None` при отсутствии модуля). Тренд — append ~200-байт строки
в `.claude/analyze/usage-trend.ndjson` (ретеншн 4000→2000, атомарная перезапись). Разделение
труда: хук = always-on коллектор · skiller analyze-run = ручной deep-dive · maind analyze =
вердикт · analyst = тренд/уроки. Читатели SCHEMA=1 значение schema не проверяют — аддитивные
поля безопасны. Фаза завершена, когда свежая сессия даёт schema=2 c usage, maind analyze
показывает tokens-блок vs медиана, а validate ловит дрейф вендоренной копии.

## Phase Handoff

Фаза B (телеметрия) завершена целиком: run-report хук поднят до SCHEMA=2 и отдаёт
`usage{totals,by_model,agents[]}` + `reads` + `error_loops` + `retrieval` + `protected_writes`;
`core/usage.py` — единый self-contained stdlib-парсер (вендорится в хук копией `_usage.py` +
`sync-usage.sh` + cmp-гейт в `validate.sh`, дрейф ловится); `skiller analyze-run` переведён на
`core.usage` (числа сходятся с regression-фикстурой один в один); `maind analyze` показывает
tokens-блок сессия vs медиана K=20 (+p90, pinned baseline.json), reason «токены ×N» → ATTENTION
(RED невозможен, Detect≠Gate); `harness doctor` детектит протухание установленной копии хука по
sha и подсказывает команду обновления.

Что даёт фазам C/D: `.claude/analyze/usage-trend.ndjson` и `tokens_slice` из maind analyze —
готовое сырьё для `core/pathology.py` (P3, детекторы патологий по токен-паттернам: file-reread,
tool-error-loop, no-op-run, overthinking и др. опираются на поля SCHEMA=2) и для analyst
token-report/агента-аналитика (P4, learning loop на исторических трендах вместо разовых сессий).

Known Deviations, оставленные в наследство: `skills-lock.json` на корне проекта, не `.claude/`
(P2.2, сверено с skillset.py — не блокер); `tool_errors` канонизирован как только
`type==tool_result` (P2.3, конвергенция, застолблена тестом).
