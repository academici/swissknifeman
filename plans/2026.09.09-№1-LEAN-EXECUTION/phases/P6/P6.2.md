### P6.2 — Deterministic Codex evaluation harness

**Intent:** Add a stdlib-only `skiller eval-context` command that executes the frozen P6 corpus through a provider adapter, captures native Codex JSONL, scores declared invariants deterministically, and resumes only against identical inputs. RAG:✅ 2026-09-09 — official OpenAI non-interactive JSONL lifecycle and sample usage fields (`findings/08-finish-external-verification.md`), confidence high for the documented surface; RAG:— (repo-grounded: `packages/skiller/lib/skiller/quality/eval.py`; D11) for repository implementation.
**Why:** The existing evaluator has useful exact assertion math and Codex probes, but ordinary skill evaluation is coupled to Claude and cannot produce a reproducible matched Codex context comparison. Ad-hoc shell loops would make ordering, retries, partial evidence and verdict math unauditable. RAG:— (repo-grounded: `packages/skiller/lib/skiller/quality/eval.py`; `findings/07-p6-design-baseline.md`; D11).
**Scope Included:** `codex-context-eval/v1` schema; case/arm loader and validation; deterministic interleaved schedule; subprocess adapter; JSONL event/usage extraction; exact and bounded assertion types; per-run error taxonomy; median/MAD reducer inputs; append-only checkpoint; digest-bound resume; redaction; fake-provider and CLI fixtures; explicit output directory and dry validation mode.
**Scope Excluded:** changing existing Claude evaluation semantics; network calls in tests; an autonomous prompt optimizer; semantic grading by another live model; accepting unparseable usage as zero; retrying indefinitely; editing instruction or skill sources; deciding the P6.3 candidate.
**Inputs:** P6.1 source/case/baseline artifacts · `research/07-p6-codex-economy.md` · D3 · D11 · current Skiller eval/CLI conventions.
**Files:** `packages/skiller/lib/skiller/quality/context_eval.py` (new) · `packages/skiller/lib/skiller/quality/eval.py` · `packages/skiller/lib/skiller/cli.py` · `packages/skiller/tests/test_context_eval.py` (new) · `packages/skiller/tests/test_eval.py` · `packages/skiller/README.md` · `packages/skiller/docs/guide/evals.md` · `CHANGELOG.md`.
**Required Reads:** 1) P6.1 state and all P6.1 deliverables 2) `research/07-p6-codex-economy.md` 3) `decisions/D11-codex-context-eval-contract.md` 4) `packages/skiller/AGENTS.md` 5) `packages/skiller/lib/skiller/quality/eval.py` 6) `packages/skiller/lib/skiller/cli.py` 7) `packages/skiller/tests/test_eval.py` 8) `packages/skiller/docs/guide/evals.md` 9) `packages/skiller/scripts/validate.sh`.
**Implementation Rules:** Keep the provider adapter injectable and subprocess-only; production argv is an explicit array and never invokes a shell. Validate the complete case and arm schema before the first call. Schedule by repetition → stable case ID → stable arm ID so matched observations stay adjacent without filesystem-order dependence. Persist source digest, case digest, harness version, provider argv/version, cwd, run key, return status, usage, wall time, invariant results and redacted event location. Resume only when all immutable digests and scheduling parameters match; otherwise fail with a named mismatch. A provider error, missing terminal event, missing usage or malformed JSONL is `invalid`, never a zero-cost observation. Retries are bounded to one transport retry and reported separately. Unit tests use a fake executable/fixture stream only. RAG:✅ 2026-09-09 — official OpenAI JSONL event/usage surface (`findings/08-finish-external-verification.md`), confidence high; RAG:— (repo-grounded: D11; `research/07-p6-codex-economy.md`) for deterministic scheduling, invalid-run and retry rules.
**Code Guidance:** Isolate pure functions for schema validation, schedule construction, event normalization, assertions and summary statistics; keep subprocess orchestration thin. Reuse only genuinely provider-neutral assertion/statistic helpers from `eval.py`; do not broaden that module with Codex-specific branching if a dedicated adapter is clearer. Normalize timestamps and repository-relative paths at render time. Test interrupted resume, digest mismatch, duplicate run keys, malformed lines, missing usage, nonzero exit, timeout, exact invariant failures, stable ordering and redaction.
**Validation:** `PYTHONPATH=packages/skiller/lib:packages/skiller/tests python3 -m unittest test_context_eval test_eval` is green without network; two fake-provider runs with identical inputs produce byte-identical normalized summaries; interruption then resume produces the same run-key set and summary as an uninterrupted fixture; changed case/source digest rejects resume before provider invocation; invalid/missing usage remains visible and excluded from medians; CLI help documents live-call boundaries; `bash packages/skiller/scripts/test.sh`, `bash packages/skiller/scripts/validate.sh` and `packages/skiller/bin/skiller registry --check` are green; when Skiller docs change, both `npm --prefix packages/skiller run docs:standalone:build` and `npm --prefix packages/skiller run docs:build` are green; `CHANGELOG.md` has an `[Unreleased]` entry.
**Deliverables:** Versioned Codex context evaluator and CLI; deterministic fake-provider test suite; digest-bound checkpoint/resume; normalized artifacts suitable for the D11 reducer without live calls in tests.
