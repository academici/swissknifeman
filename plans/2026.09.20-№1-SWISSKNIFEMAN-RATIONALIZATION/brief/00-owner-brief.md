# Owner brief — 2026-09-20

Создать executable master-plan рационализации swissknifeman по аудиту
`audits/2026-09-20-perplexity.md`.

Обязательные границы:

- ровно пять крупных фаз;
- каждая фаза детализируется отдельно и в несколько заходов;
- несущие внешние тезисы перепроверяются и Perplexity, и обычным web search;
- field audit corex, agentools и edufy выделен в самостоятельную фазу;
- ценность maind memory и code graph измеряется, а не предполагается;
- для детализации фаз выбирается Grok 4.6 или Composer 2.5;
- реализуется только измеримо нужное;
- углублённая test-программа не строится;
- в этом design-ходе нет продуктовых изменений, документация продукта не требуется;
- существующие dirty trees сохраняются.
