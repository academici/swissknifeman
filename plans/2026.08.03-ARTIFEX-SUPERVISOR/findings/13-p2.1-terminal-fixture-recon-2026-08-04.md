# P2.1 terminal-fixture recon — 2026-08-04

## Trigger

P2.3 ran its required predecessor validation and stopped before committing because
`test_compiler.py` no longer reaches the compiler. `_sources()` calls the live Harness P2 dry-run,
then searches `s3["items"]` for P2.2 and relabels that row as pending P2.1. P2.2 is now terminal,
so Harness correctly places it in `excluded_terminal`; `next(...)` raises `StopIteration`.
RAG:— (repo-grounded: `artifacts/supervisor/tests/test_compiler.py` and the reproduced unittest
output on 2026-08-04).

## Repository observations

- `packages/harness/bin/harness run 2026.08.03-ARTIFEX-SUPERVISOR P2 --dry-run --json`
  returns `degraded=false`, runnable rows only in `items`, and P2.1/P2.2 in
  `excluded_terminal` with `ITEM-TERMINAL`.
- Harness documents and implements terminal exclusion deliberately; there is no
  `--include-terminal` mode. RAG:— (repo-grounded:
  `packages/harness/lib/harness/run/plan_reader.py:262-358`,
  `packages/harness/docs/reference/exec-wave.md`).
- The compiler's `observe_sources()` may still obtain S1/S2/S3 process payloads for inspection,
  but `compile_slice()` correctly requires one pending matching row in `s3["items"]`. Production
  behavior must not be weakened to compile a terminal slice. RAG:— (repo-grounded:
  `artifacts/supervisor/artifex/compiler.py`).
- P2.3's uncommitted `authority.py`/`test_authority.py` are unrelated scope and remain untouched.

## Verdict

The defect is test isolation owned by P2.1, not Harness behavior and not P2.3. Compiler conformance
tests need a literal item-owned S3 fixture whose expected route/Exec/refusal values come from the
frozen P2.1 spec, not from candidate code or a live sibling item. A separate live boundary test
must assert that closed P2.1 is excluded from runnable `items` and appears in
`excluded_terminal`; that observation remains stable as later items close.

No external fact class is decision-bearing. No package/public contract, production compiler
semantics, P1 frozen contract, or P2.2 artifact needs a change.
