# P3 — Ценность maind memory и code graph

## Phase Context

P3 сначала доказывает coverage телеметрии и provider parity, а затем отдельно измеряет
maind memory и code graph на малом matched corpus. Текущие 96 run reports с нулевыми calls и
`code_mcp=false` — это evidence gap, а не вердикт о нулевой ценности. Пилоты идут в
временных чистых worktrees и измеряют время, контекст, точность навигации и повторную работу.

**Scope Included:** telemetry coverage; memory vs no-memory pilot; codegraph vs ordinary-search pilot; practical effect sizes; independent go/keep/defer/reject verdicts.
**Scope Excluded:** full factorial benchmark; production rollout; permanent activation; combined verdict, hiding separate effects.

> **Контракт фазы (contract-first).** Потребляет: P1 measurement contract и P2 field evidence · Производит: отдельные memory/codegraph verdicts и границы их применимости · Границы: без rollout и permanent config changes.

> **Phase Assurance | v1.**
> Impact: internal-integration
> Integration Seams: `memory-value` · `codegraph-value` · `telemetry-coverage`
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: Парные пилоты, явная coverage-проверка и раздельные verdicts должны закрыть риск ложного вывода из нулевой телеметрии.
