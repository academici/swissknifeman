### P1.1 — Заморозить verified baseline и measurement contract

**Intent:** Независимо перепроверить внешние предпосылки и repository claims исходного аудита, затем заморозить воспроизводимый baseline и малый measurement contract, которые P2–P5 могут использовать без нового толкования.
**Why:** RAG:— Внешний аудит не имел локального checkout, а нулевые maind/codegraph счётчики в текущей выборке одновременно сосуществуют с неполным provider coverage и выключенным code MCP. Без разделения value от observability/activation gap любое удаление было бы недоказанным.
**Scope Included:** Двойная внешняя перепроверка Perplexity + ordinary web с открытием первичных источников; git-tracked baseline root/provider instructions, Task/skills surfaces, имеющихся budget/run-report/memory/codegraph инструментов и CI definitions/evidence; малый real-task corpus; paired controls, метрики, practical-effect thresholds, invalid-run policy, budget и stop rules; классификация гипотез в `verified|unverified|coverage-gap`.
**Scope Excluded:** Любые product/runtime/docs/CHANGELOG правки; запись в corex/agentools/edufy; live benchmark runs; включение code graph или telemetry; `maind health --fix`, deploy/sync/onboard; смена provider/model mappings; исправление найденных дефектов; full statistical/test programme; verdict о конкретных rationalization slices.

**Implementation Rules:** Сначала зафиксировать commit, scoped `git status`, версии доступных provider CLI и инвентарь evidence sources; dirty state — граница измерения, не cleanup target. Один и тот же claim set прогнать через Perplexity `search_advanced` (`web` + `academic`) и ordinary web search; для несущего вывода открыть primary source, записать URL, дату доступа, класс источника и ровно поддержанный тезис; discovery summary не является proof. Каждый repository claim проверить по tracked code/config/test или воспроизводимой read-only команде; отдельно записать instrument existence, provider coverage, activation state, sample denominator и observed value. Нуль при missing/disabled coverage остаётся `coverage-gap`, а не value verdict. Использовать только read-only режимы существующих `skiller`, `maind`, `analyst`, git/GitHub и plan tools; optional host/provider evidence при недоступности помечается `n/a`, но не подменяется нулём. Measurement contract берёт из recent repository history не более шести реальных tasks по классам narrow fix, ordinary implementation, review, research/design, durable plan и environment/setup; для отдельного slice используется только релевантное подмножество. Пара A/B меняет один механизм при одинаковых commit, prompt, provider/model/effort, tools, sandbox, timeout и acceptance; порядок сторон чередуется. На slice — не более шести task pairs и один повтор только для инфраструктурно невалидной или decision-boundary пары; затем обязательный stop. До первого будущего прогона заморозить denominators, exclusion/invalid rules, practical-effect thresholds и reducer `go|keep|defer|reject`; ambiguous/under-covered result никогда не превращается в `go`.
**Code Guidance:** Предпочитать существующие budget, run-report, sessions, codegraph-usage и plan validators. Не добавлять скрипт, schema, telemetry field или генерируемый carrier ради P1; доказанный instrumentation gap записывается как input P4/P5, а не чинится в этом item. В обоих output отделять observed facts от inference и не переносить vendor facts между providers без проверки.
**Validation:** 1) `findings/01-p1-verified-baseline.md` содержит claim ledger с `RAG:✅|RAG:—|[UNVERIFIED]`, source/access date, repository path/symbol или command, provider/coverage/denominator и verdict; каждая рекомендация исходного аудита либо опирается на evidence, либо остаётся hypothesis/coverage gap; 2) `research/02-p1-measurement-contract.md` содержит exact corpus provenance, A/B controls, primary/guardrail metrics (acceptance, instruction violations, unrelated writes, input/output tokens where observable, wall time, tool calls/reads, owner interruptions, false activations, recovery/usefulness), fixed thresholds, invalid/exclusion rules, per-slice run cap, stop rules и reducer всех четырёх verdict; 3) scoped `git diff --name-only -- plans/2026.09.20-№1-SWISSKNIFEMAN-RATIONALIZATION` и `git status --short` доказывают, что item не менял product files и не присваивал чужой dirty state; 4) `python3 packages/task/scripts/verify-plan-citations.py --strict plans/2026.09.20-№1-SWISSKNIFEMAN-RATIONALIZATION`; 5) `python3 packages/task/scripts/plan-views.py bundle --plan-dir plans/2026.09.20-№1-SWISSKNIFEMAN-RATIONALIZATION --item P1.1 --check`; 6) `python3 packages/task/scripts/plan-lint.py plans/2026.09.20-№1-SWISSKNIFEMAN-RATIONALIZATION`; 7) `git diff --check -- plans/2026.09.20-№1-SWISSKNIFEMAN-RATIONALIZATION`.
**Deliverables:** 1) `findings/01-p1-verified-baseline.md` — воспроизводимый external/repository claim ledger, current instrumentation/coverage matrix, evidence gaps и нейтральный hypothesis inventory без implementation verdict; 2) `research/02-p1-measurement-contract.md` — замороженный bounded protocol для P2–P5, включая exact stop budget и decision reducer; 3) GREEN plan/citation/bundle/diff evidence и явный список `n/a`/coverage gaps; 4) ноль product/runtime/consumer-tree changes.
