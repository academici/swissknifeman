# P1 — settings-doctor: конфликт-линтер настроек Claude Code

## Phase Context

Фаза заводит doctor настроек Claude Code: читает все слои (user → project → local → managed),
строит ЭФФЕКТИВНУЮ конфигурацию с провенансом и репортит конфликты — таксономия из 13 проверок
(спека `roadmap/settings-doctor.md`). Повод — полевой кейс 2026-07-10: промпты каждые полминуты
при `bypassPermissions` в local, неустановленный safe-dirs-хук, ~400 мёртвых allow-правил,
неканонический `permissions.autoApprove`.
Дом движка — пакет **harness** (`lib/harness/settings_audit.py`, CLI `harness doctor --settings`):
он SSOT окружения Claude Code и владелец писателя `scripts/apply-permissions.sh` — doctor обязан
быть парой к писателю (D10, уточняет D8). Фасады: `skiller doctor --settings` (subprocess) и
fleet-скан `maind doctor --audit settings`. Новых пакетов не заводим.
Проект объявляет ожидаемую политику ключом `policy_profile` в `.swissknife.json` (D11), профили
живут рядом с пресетами — `configs/claude-code/policy/<name>.json`; doctor сверяет факт с
декларацией и read-only (авто-починки нет).
Несущие внешние факты сверены дважды — `findings/P1-cc-settings-facts.md` (D3/D5/D6 — расхождения
спеки с доками; D13–D15 — снапшот ключей, VSCode-ключи, неопределённость `additionalDirectories`).
Фаза закрыта, когда doctor ловит все 6 пунктов полевого кейса (интеграционный тест P1.5),
fleet-измерение работает, а `roadmap/README.md` помечает `settings-doctor` как внедрённый.

**Scope Included:** движок слоёв/merge/провенанса в harness · 13 проверок таксономии · 2 policy-профиля
(`max-permissive`, `base`) + декларация `.swissknife.json:policy_profile` · CLI `harness doctor
--settings` (отчёт, `--json`, exit-code 0/1/2) · фасад `skiller doctor --settings` · fleet-измерение
`maind doctor --audit settings` · VSCode-слой (2 ключа) · доки пакета, корневой CHANGELOG,
статус в `roadmap/README.md`.

**Scope Excluded:** opt-in `UserPromptSubmit`-хук с дневным sentinel (п.3 «Точек интеграции» спеки —
D12: критерий не сработал, резидентный расход на каждый промпт) · авто-починка найденного (`--fix`;
doctor read-only, писатель — `harness permissions`) · сетевой фетч JSON-схемы в рантайме (D13) ·
