# Roadmap: align `plan-views history` CLI contract with its callers

**Status:** ⬜ к внедрению. **Owner:** `packages/task`.

## Measured mismatch

`plan-views.py history` renders history to stdout by default and rejects `--stdout`, but
`2026.08.10-TASK-LEAN-AUTONOMY P1.2` and the generated item-state command prescribe:

```bash
python3 packages/task/scripts/plan-views.py history --item P1.2 --stdout --plan-dir <plan>
```

The CLI deterministically returns `ERROR: history требует --item и не принимает --all` because
the handler's condition also rejects `args.stdout`. The minimal working invocation is:

```bash
python3 packages/task/scripts/plan-views.py history --plan-dir <plan> --item P1.2
```

## Required change

Choose one canonical interface and regenerate every caller/help projection together. Prefer making
`history --item` stdout implicit in command/spec/state text; add a regression test that the emitted
command executes successfully. Do not add a second telemetry/read carrier.
