## 1. Пять источников `skiller budget --first-turn` — что каждый читает

RAG:— (repo-grounded: `packages/skiller/lib/skiller/budget.py`, 809 строк на `88164708`;
определения `_measure_*` — строки 242 / 265 / 282 / 362 / 380).

| Источник | Функция | Читает ФИЗИЧЕСКИ | Видит marketplace-плагин? |
|:--|:--|:--|:--|
| skills | `_measure_skills` (242) | `resolve_active_set(env, target)` — skiller-собственный реестр + `<target>/.swissknife.json` | **нет** |
| agents | `_measure_agents` (265) | `<target>/.claude/agents/*.md` frontmatter | **нет** |
| claude_md | `_measure_claude_md` (282) | `<target>/CLAUDE.md` + `<target>/.claude/rules/*.md` без `paths:` | **нет** |
| hooks | `_measure_hooks` (362) | команды `SessionStart` из `<target>/.claude/settings*.json` (`_settings_hook_commands`) | **нет** |
| mcp | `_measure_mcp` (380) | `<target>/.mcp.json` → `mcpServers` | **нет** |

**Общий знаменатель:** каждый источник строит путь от `Path(target)` — корня ЦЕЛЕВОГО ПРОЕКТА.
Ни один не открывает `~/.claude/plugins/**` (кэш установленных marketplace-плагинов) и ни один
не читает ключ `enabledPlugins` глобального `~/.claude/settings.json`.

**Вывод (не оценка, а свойство кода):** инструмент по построению меряет **skiller-поверхность
конкретного проекта**. Marketplace-плагин Claude Code ставится в пользовательский scope и
поэтому находится вне области определения инструмента — это не баг замера и не «плагин
бесплатный».

## 3. Нативный измеритель: `claude plugin details` — что он даёт

Команда:

```bash
claude plugin details codex@openai-codex
```

Вывод (снят 2026-07-29, дерево `88164708`, `--json` у команды **нет** — проверено
`claude plugin details --help`: единственная опция `-h, --help`):

```
codex 1.0.6
  Use Codex from Claude Code to review code or delegate tasks.
  Source: codex@openai-codex

Component inventory
  Skills (11)  adversarial-review, cancel, codex-cli-runtime, codex-result-handling,
               gpt-5-4-prompting, rescue, result, review, setup, status, transfer
  Agents (1)  codex-rescue
  Hooks (3)  SessionStart, SessionEnd, Stop  (harness-only — no model context cost)
  MCP servers (0)
  LSP servers (0)

Projected token cost
  Always-on:   ~449 tok   added to every session

Per-component (rounded)
  component              always-on  on-invoke
  codex-cli-runtime            ~40      ~1.1k
  codex-result-handling        ~30       ~580
  gpt-5-4-prompting            ~60      ~1.3k
  codex-rescue                 ~80      ~1.1k
  cancel                       ~20        ~30
  result                       ~30       ~170
  status                       ~30       ~210
  transfer                     ~30        ~80
  review                       ~20        ~1k
  rescue                       ~40      ~1.2k
  adversarial-review           ~40      ~1.2k
  setup                        ~40       ~320

  On-invoke cost is paid each time a skill or agent fires.
  Token counts are estimates and may differ from actual usage.
```

**Что это даёт и чего не даёт:**

- **Даёт:** always-on цену плагина числом (**~449 ток**), покомпонентную разбивку и явное
  разделение always-on / on-invoke; сам инструмент помечает свои три хука как
  `harness-only — no model context cost`, то есть цена хуков в контекст не входит.
- **Не даёт:** суммарного первого хода ПРОЕКТА (это предмет `skiller budget --first-turn`);
  машинного `--json` (парсить придётся текст либо приводить число вручную); собственных
  порогов/вердикта.
- **Совместимость чисел:** обе оценки — приблизительные («Token counts are estimates»
  у одного, «это оценка, как и весь budget.py» у другого, `_measure_mcp` docstring), поэтому
  складывать их в одну сумму допустимо только как ОЦЕНКУ, что и делается в процедуре.

**Сверка состава с финдингом 2026-07-08** (`findings/P7-codex-delegation-facts.md` §1.1):
финдинг называл 8 команд + субагент + 3 скилла + `hooks/hooks.json`. Фактическая установка
2026-07-29 (версия плагина **1.0.6**) даёт **11 скиллов + 1 агент + 3 хука**, MCP-серверов 0.
Расхождение датировано и записано здесь, слой 1 задним числом не переписывается.

## 4. Факт установки — машинное состояние вне репозитория

```bash
jq '.enabledPlugins' ~/.claude/settings.json      # содержит ключ codex@openai-codex
git status --short                                 # следов установки в репозитории нет
```

Соответствует D61: дом операции — `/maind:plugins`, состояние живёт в
`~/.claude/settings.json` (`enabledPlugins` / `extraKnownMarketplaces`), в `Files` плановых
items не выносится, межплановых пересечений не создаёт.

## 5. Что из этого следует для правила гейта

Сведено в слой 2 — `research/28-P7.3-redesign-2026-07-29.md`. Кратко: измеритель и предмет
измерения принадлежат разным поверхностям, поэтому гейт CLAUDE.md обязан называть ДВА
инструмента по классу инжекта, а правило отката — опираться на **дельту от установки**, а не
на унаследованный суммарный WARN проекта.
