## Решение

Rewrite the P4.2 Validation carrier so every executable snippet is an explicit root-relative
command. Preserve `packages/skiller` as the recorded cwd identity, not as a standalone fenced
command candidate.

## Почему

P2.1 downstream evaluation parsed the prose fragment ``In `packages/skiller` `` as a command and
received exit 126 because the path is a directory. The intended Skiller scripts were already
named later in the same Validation field. Root-relative spellings preserve the exact validation
meaning while making command extraction deterministic and executable.

## Consequences

The historical red downstream finding for P4.2 remains immutable evidence for the old consumer
spec digest. A repeated P2.1 downstream record binds the repaired P4.2 spec digest and must no
longer execute a directory. D76 changes no P4.2 scope, package ownership, acceptance, or product
file.
