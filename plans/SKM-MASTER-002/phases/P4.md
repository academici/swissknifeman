# P4 — Analyst learning loop (фаза D)

## Phase Context

Замыкаем learning loop analyst поверх телеметрии (P2) и патологий (P3): команда
`analyst token-report` (срезы по model/role/phase, двухслойный baseline: rolling медиана+p90
K=20 и pinned через `--baseline set`), агент-аналитик `analyst.md` + команда `/analyst:deep`
(digest-first: скрипты дают JSON, raw-транскрипты запрещены — D16), `analyst ingest` для
findings агента (только ephemeral-уроки, промоут остаётся за человеком) и `analyst proposals`
(типы stack-pack/project-override/docs; каталог `~/.swissknifeman/analyst/proposals/`;
analyst никогда не пишет в шаблоны/проекты — печатает handoff-последовательность).
Алертинг регрессий: maind analyze reason `⚠ токены ×N` при >max(1.5×median, p90);
digest token-regression при ≥3/5 сессий над порогом. Инварианты пакета неприкосновенны:
человек в гейте промоута, privacy (сырьё LOCAL), детерминированный stdlib-слой.
Агент — экосистемно-единый (в пакете analyst, раздаётся marketplace), запуск on-demand
(после ATTENTION-серии/еженедельно), НЕ per-session. Фаза завершена, когда token-report
рисует таблицу с baseline, /analyst:deep работает digest-first, а proposals не пишут вне
своего каталога.

### P4.2 — Агент-аналитик + /analyst:deep + ingest

**Status:** 🟠 Done with deviations
**Intent:** Создать `packages/analyst/agents/analyst.md` (opus-tier, read-only tools), команду `/analyst:deep` (digest-first) и `analyst ingest --file F` для findings агента.
**Why:** Скрипты не умеют каузальный нарратив, hidden scope expansion, качество handoff, деградацию cheap-моделей, resolve CONFLICT, тексты remediation — это ниша агента; но сырьё ему давать нельзя (токены + privacy).
**Scope Included:** агент (read-only); deep.md: сначала прогоняет `maind analyze --json` + `token-report --json` + `review --json`, агенту передаются пути к JSON; raw-транскрипты запрещены промптом; ingest: валидация схемы findings → classify_consolidation → только ephemeral-уроки (`detector=agent-finding`) + audit-запись; перегенерация registry (агент/команда попадают в marketplace).
**Scope Excluded:** авто-промоут (человек в гейте — инвариант); harness agent-pack (агент экосистемно-единый, версионируется с CLI); per-session запуск.
**Inputs:** зависит от P3.* (детекторы дают материал) и P4.1 (token-report --json).
**Files:** packages/analyst/agents/analyst.md · packages/analyst/commands/deep.md · packages/analyst/lib/analyst/ingest.py · packages/analyst/lib/analyst/cli.py
**Required Reads:** 1) packages/analyst/lib/analyst/digest.py (classify_consolidation, схема уроков) 2) packages/analyst/lib/analyst/review.py 3) packages/analyst/commands/ (стиль существующих команд) 4) packages/analyst/CLAUDE.md (инварианты)

### P4.3 — analyst proposals + handoff-печать
