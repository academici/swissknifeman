## [Unreleased]

### Added
- **Sync:** `workspace sync [--commit] [--pull] [--push] [--resolve PATH=local|remote ...] [--resolve-reset]` (`sync.py`, PLAN6 P4.2) under `git.lock`. Commit: publish-safety first (`PUBLISH_BLOCKED` commits nothing), local-only files to `local-only.json` and the exclude block, a tracked file that became local-only leaves the index (`git rm --cached`, warning), the execute bit is cleared in the index, `git add -A` of the layout paths, commit `skm(plan): <plan-id> sync <N> files` or `skm(workspace): sync <N> files` with `Workspace-Device`. Pull: `git fetch`, `git merge-tree --write-tree --name-only -z`, merge when clean (fast-forward where possible), else `WORKSPACE_CONFLICT` with `conflicts[{path, project_id, plan, ref}]` and an untouched working tree and `HEAD`. Resolve: decisions per path in `sync.json.pending_resolutions` for the paths of `last_conflicts` (`RESOLUTION_INCOMPLETE` otherwise), the merge when all are decided and `origin/<branch>` and `HEAD` did not move (`WORKSPACE_CONFLICT_STALE`), `git merge --abort` on any error, `--resolve-reset`. Push: `git push origin HEAD:<branch>` without force, remote and branch printed first, `WORKSPACE_BEHIND`. No flag means commit and pull; `--push` implies both; `--resolve` replaces `--pull`. New codes `REMOTE_NOT_SET`, `WORKSPACE_MERGE_FAILED`, `WORKSPACE_MERGE_IN_PROGRESS`, `WORKSPACE_UNRELATED_HISTORIES`, `WORKSPACE_SYNC_FAILED`. `sync.json` and `audit.jsonl` in the machine state; events `workspace.sync.committed|pulled|conflict|pushed` with schemas in `schemas/event-data/v1`. Test `tests/test_sync.py` (including a check of the argument list of every git call for force push, `reset --hard`, `clean`, `checkout .` and `rebase`); `scripts/e2e-workspace-sync.sh` (two machines, one bare remote).
- **Remote:** `workspace connect --remote URL [--branch B]` classifies the remote with `git ls-remote --heads` and a temporary shallow clone in `.staging/connect-<id>` (`empty` or `same`; `REMOTE_FOREIGN`, `REMOTE_OTHER_WORKSPACE`, `REMOTE_UNREACHABLE`, `REMOTE_ALREADY_SET`) and then only adds `origin`; it never commits or pushes. `workspace clone URL [--root DIR]` clones into an absent or empty folder (`WORKSPACE_ROOT_NOT_EMPTY`), checks `workspace.json` and creates the device when the machine has none. `workspace status --fetch` fetches `origin` and reports ahead/behind/diverged against `origin/<branch>`. Git calls that reach a remote never prompt (`GIT_TERMINAL_PROMPT=0`, ssh `BatchMode`); URLs in output and errors carry no user information; git older than 2.38 is `WORKSPACE_GIT_TOO_OLD` (`remote.py`, `gitutil.require_version|network|fetch|ahead_behind`).
- **Migration:** `workspace migrate discover|plan|apply|verify|rollback|cleanup` (`migrate.py`, `migrator_port.py`). `plan` is a dry run that writes nothing (classes, digests, publish-safety, comparison with the workspace, blockers; exit 1 on a blocker); `apply` calls the port `workspace:plans-migrator` and then writes `local-only.json`, the exclude block, the report `migrations/<op_id>.json`, the binding and the event `workspace.migration.applied`; `verify`, `rollback` (event `workspace.migration.rolled-back`) and `cleanup --confirm <project_id>` follow `workspace-contract#migration`. Nothing here commits; `apply`, `rollback` and `cleanup` print `next`. Refusals: `MIGRATION_CONFLICT`, `MIGRATION_IN_PROGRESS`, `MIGRATION_BLOCKED_SECRET`, `MIGRATION_BLOCKED_SYMLINK`, `MIGRATION_LOCKED`, `MIGRATION_DIVERGED`, `CLEANUP_CONFIRM_MISMATCH`, `MIGRATOR_UNAVAILABLE`, and `MIGRATION_NOT_APPLIED` (rollback, cleanup or verify without an applied migration of this device).
- **Doctor:** the check `workspace.plans-migrator` (warns when no plugin fills the port).
- **Publish-safety:** `workspace doctor --publish-safety [--all] [--json]` applies the rules `PS-SECRET`, `PS-MANIFEST-PATH`, `PS-SYMLINK`, `PS-TOP-LEVEL`, `PS-PROJECT-LEVEL` (block), `PS-EXECUTABLE`, `PS-HOME-PATH`, `PS-TRACKED-LOCAL-ONLY` (warn), `PS-SIZE`, `PS-BINARY` (local-only) to the files of the next commit (or all files) and prints a `publish-report/v1` document (`schemas/publish-report/v1`); exit 1 and `PUBLISH_BLOCKED` on a block. A secret is never printed. `safety.scan|check|changed_paths|all_paths` and `localonly.update|rebuild_exclude|entries_by_project|device_paths` are the functions sync and migrate reuse.
- **Local-only index and exclude block:** `projects/<id>/local-only.json` records the files kept out of git; the block `# skm:local-only begin` … `end` of `.git/info/exclude` is rebuilt whole from the entries of this device.
- **New module `workspace` (0.1.0, `development`, `destination: hub`):** `swissknifeman workspace init|status|doctor` and `project attach|list|show|scan|rebind|detach` over the places, documents, bindings and resolver of `aicore.workspace` (ADR 0085). `init` creates the layout, the git repository (`main`, first commit with a `Workspace-Device` trailer) and the device file; a repeat is a no-op and a non-empty folder is `WORKSPACE_ROOT_NOT_EMPTY`. `attach` identifies a checkout by its marker, else by matching remotes (never by name; `ATTACH_CONFIRM_REQUIRED` without `--yes` and a terminal, `PROJECT_AMBIGUOUS` for several matches), writes the marker without committing it and binds the checkout. `doctor` returns `check-result/v1` documents.
- **Configuration `[workspace]`:** `publish.max_tracked_bytes`, `publish.max_binary_tracked_bytes`, `git.lock_timeout_s`, `plans_migrator`.
- **Events** `workspace.root.initialized`, `workspace.project.attached`, `workspace.migration.applied` and `workspace.migration.rolled-back` with data schemas in `schemas/event-data/v1`; the extension point `plans-migrator`.
