# P4 — Terminal delivery and provider boundary

## Phase Context

P4 closes the repository-owned false-terminal seam without claiming control over every provider
transport. P4.1 adds one provider-neutral Task lease/admission contract over the current plan run,
P1.3 continuity decision, delivery receipt and exact proposed final message. P4.2 projects that
contract into documented Codex and Claude Code `Stop` hooks through Harness and records capability
limits for untrusted, unconfigured or hook-less surfaces. Completion means an active Task run can
emit a machine-readable `final_allowed` verdict at every supported stop attempt, continue on a
non-terminal verdict, and allow only the exact receipt-bound terminal response; the forty-boundary
fixture proves the local state machine with advancing progress rather than an impossible provider
promise. RAG:✅ for current provider hook behavior; RAG:— for repository contracts.

**Scope Included:** Task active-run lease and terminal-admission event; exact final-message binding;
P1.3 continuity consumption; Codex/Claude Code Stop adapters; opt-in/trust/kill-switch semantics;
provider capability evidence; forty advancing artificial boundaries; generated projections.
**Scope Excluded:** duplicating the P1.3 session-continuity controller; raw transcript retention;
unbounded or provider-independent stop control; automatic owner approval; hook installation outside
Harness ownership; claims about ChatGPT web, IDE, cloud or other undocumented surfaces.

> **Phase Assurance | v1.**
> Impact: internal-integration
> Integration Seams: `task-terminal-admission` · `harness-provider-stop` · `delivery-receipt`
> Live or Irreversible: no
> Audit Intent: required
> Rationale: Task state, provider hook rendering and support claims must fail and recover together.

> **Контракт фазы (contract-first).** Потребляет: P1.3 continuity decision + current delivery receipt · Производит: lease-bound `final-admission-event/v1` + provider-native allow/continue response · Границы: only configured documented Stop surfaces are enforceable.
