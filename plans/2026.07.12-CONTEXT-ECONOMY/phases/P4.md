### P4.1 — Диета описаний во всех паках + бамп версий

**Status:** ⬜ Not started
**Intent:** Сократить `description:` frontmatter агентов всех 10 паков до ~300–500B (cap 600B), оставив 1 самый показательный `<example>`; бампнуть version в pack.json каждого затронутого пака + записи per-pack CHANGELOG.
**Why:** Описания агентов резидентны в каждой сессии проекта с паком (~2K ток/пак); 3 example-блока — избыточны для маршрутизации (1 позитивного + краткого анти-триггера в прозе достаточно).
**Scope Included:** agents/*.md всех паков (backend-laravel 9, laravel-package 7, python-backend/node-frontend/dart-flutter по 5, role-* по 3, _common 1); pack.json версии; per-pack CHANGELOG.md.
**Scope Excluded:** тела агентов (после frontmatter); rules/commands/workflows паков; re-render на проекты (P6.2); движок agentpacks.py (кроме ничего — только конфиги).
**Inputs:** Замер до (B): reviewer 1345 · spec-writer 898 · test-writer 886 · slice-builder 855 · route-mapper/test-verifier/security-review/db-impact 543–583 · blade-review 483 (backend-laravel, сумма 6.9KB → цель ≤3.5KB). Прецедент бампа версии: коммит 4e3af7b.
**Files:** packages/harness/configs/claude-code/agent-packs/*/agents/*.md · packages/harness/configs/claude-code/agent-packs/*/pack.json · packages/harness/configs/claude-code/agent-packs/*/CHANGELOG.md
**Required Reads:** 1) packages/harness/configs/claude-code/agent-packs/backend-laravel/agents/reviewer.md (худший — паттерн правки) 2) packages/harness/configs/claude-code/agent-packs/backend-laravel/pack.json 3) git show 4e3af7b (прецедент дисциплины бампа) 4) packages/harness/CLAUDE.md (конвенции agent-packs)
**Implementation Rules:** Шаблонные токены `{{...}}` в description сохранять как есть; description остаётся триггер-полным: роль + когда звать + 1 example + анти-триггер одной фразой; язык описаний не менять (какой был); формат frontmatter не ломать (парсится agentpacks.py).
**Code Guidance:** Сокращение — выбор лучшего example (самый частотный сценарий), НЕ механическое обрезание первых N байт. Никакой подгонки под cap: если у конкретного агента 500B не хватает для однозначного триггера — оставить до 600B и зафиксировать в Completion Notes почему. После правки каждого пака — локальный рендер-смоук (`harness agent-packs render` в tmpdir, как в существующих тестах) — рендер не падает. Version bump: patch если только description, по прецеденту 4e3af7b. Не трогать агентов, чей description уже ≤500B.
**Validation:** скрипт-подсчёт: все description ≤600B, сумма по backend-laravel ≤3.5KB; существующие тесты agent-packs harness зелёные; `bash packages/harness/scripts/validate.sh` зелёный.
**Deliverables:** правки agents/*.md по пакам + бампы pack.json + CHANGELOG-записи; таблица было→стало (B) по пакам в Completion Notes.
