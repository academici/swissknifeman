# P2 — Build the plan-local deterministic prototype

## Phase Context

P2 builds the stdlib-only deterministic core under this plan, without provider dispatch or live
package topology changes. Execution is hard-gated on terminal P0/P1 and a green P1.5 aggregate
contract manifest; the currently planned P1 files are future inputs, never assumed evidence.

**Scope Included:** process-bound canonical plan/Task Contract consumption, immutable slice
compilation, strict hash-chain run storage, replay/snapshot/locking, total authority evaluation,
dependency/budget/circuit-breaker scheduling, and a plan-local start/status/resume/reconcile/stop/report CLI with deterministic tests.

**Scope Excluded:** Codex/Claude argv or live worker dispatch; plan status mutation; changes under
`packages/**`, `core/**`, provider/fleet/Brain/generated/release state; package/root CLI promotion;
external services, credentials, raw prompts/transcripts/thinking/tool payloads; claims of physical
power-loss durability or product economics.

> **Контракт фазы (contract-first).** Потребляет: terminal P0 gates + terminal P1 five-contract manifest, contracts, cases and validators + live read-only Task plan-model/Task Contract and Harness process boundaries · Производит: plan-local compiler, run store, authority evaluator, scheduler and no-provider CLI candidate with aggregate tests/manifest · Границы: no provider dispatch until P3; no plan status writer, package/root CLI promotion or hook remediation.

Items execute strictly P2.1→P2.5. No workflow is declared: every item consumes predecessor code
and P2.5 is the aggregate integration gate. RAG:— (repo-grounded:
`research/08-p2-prototype-design.md`; `research/14-p2.1-source-reconciliation.md`).
