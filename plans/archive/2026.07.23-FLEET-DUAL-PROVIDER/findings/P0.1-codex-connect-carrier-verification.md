## Официальная поверхность Codex

Источник: локальный verified cache официального Codex manual,
`/tmp/openai-docs-cache/codex-manual.md`, страница **Build plugins**, блоки
`Build your own curated plugin list`, `Install a local plugin manually`,
`Marketplace metadata` и `How the ChatGPT desktop app uses marketplaces`.

Проверенный вывод:

- `$REPO_ROOT/.agents/plugins/marketplace.json` является repo-scoped
  marketplace surface;
- local plugin `source.path` задаётся `./`-prefиксным путём относительно корня
  marketplace и должен оставаться contained внутри него;
- repo marketplace лишь публикует доступный plugin set, а install/cache/enable
  выполняются отдельно на user-level surface;
- локальная установка загружает копию из user cache, поэтому внешний consumer
  не может ссылаться thin path на checkout skiller.

Вердикт: P0.1 может заменить self-host-only отказ repo-contained marketplace с
self-contained selected bundles, не вызывая `codex plugin` и не меняя frozen
install boundary. RAG:✅ 2026-07-23, official Codex manual / Build plugins.

## Environment preflight syntax

Ошибочная форма:

```text
./packages/maind/bin/maind health --cwd /home/vostrikov/projects/packages/swissknifeman
```

Результат: exit `1`, `ERROR: лишние аргументы`; `--cwd` является boolean flag и
не принимает путь.

Поддерживаемая worktree-local форма:

```text
./packages/maind/bin/maind health --cwd
```

Результат: exit `0`, `project:swissknifeman`, status `connected`. Неуспешная
форма не считается green и сохранена как диагностический факт.
