# P1 — Provider config/domain и backward-compatible resolution

## Phase Context

P1 запечатывает композицию project/fleet provider config и реализует общий stdlib-only
domain/resolution seam, который затем потребляют P2–P7. Фаза сохраняет владение файловыми
форматами у `skiller` (`.swissknife.json`) и `maind` (`config.json`), а в `core` помещает
только immutable domain, minimal adapter protocols и pure resolver с provenance/diagnostics.
Старые конфиги без `providers` обязаны давать прежний Claude Code-only effective result
без записи на диск. P1 не генерирует `.claude`/`.codex` artifacts и не включает Codex во
fleet автоматически.

**Scope Included:** draft→frozen provider-config contract; stable config carriers и
precedence; provider domain + adapter interfaces; pure resolution/provenance/diagnostics;
thin schema/validation adapters в `skiller`/`maind`; legacy and override fixtures.

**Scope Excluded:** provider renderers/lock/drift engine (P2); skills/task/harness/mAInd
delivery behavior (P3–P6); изменение реального корневого `config.json`; запись в consumer
projects; исполнение/редактирование FOREMAN; fleet rollout; bootstrap cleanup.

> **Контракт фазы (contract-first).** Потребляет: terminal P0.3/P0.4, frozen v1.0.0 capability/artifact/migration-gate contracts, approved glossary/scenarios и D1–D12 · Производит: frozen provider-config contract, public core provider/resolver API, package validation seams и anchored compatibility matrix · Границы: не генерирует provider artifacts, не меняет provider-specific delivery, FOREMAN или fleet state.

D13–D15 являются локальными design constraints P1 и не объявляются output предыдущей
фазы. RAG:— (repo-grounded: `plan.md` D13–D15)

**Entry gate:** пройден перед P1.1: P0.3/P0.4 terminal, P0 contracts frozen v1.0.0 по
D55/D59, latest independent Audit P0 имеет literal GREEN на `245bb56`, G01 открыт.
RAG:— (repo-grounded: `phases/P0.md`, `plan.md` D55/D59/D67–D69,
`root/contracts/provider-{capability,artifact,migration-gates}.md`)
