## Дефекты механизма

1. Прогон не стартует при неотслеживаемом файле владельца (`WORKTREE_DIRTY`, `ideas/`). Не дефект, но правило: перед прогоном дерево чистое. Предложение: опция игнорирования путей `ideas/`.
2. `RESULT_HEALED` + `RESULT_REPAIRED` на первом отчёте исполнителя (`stage-report` не JSON, запятая, строка 13). Один случай; следить за повтором — если растёт, править контракт промпта.
3. Наблюдатель не поставил монитор завершения прогона и не сообщил о конце пункта вовремя (ошибка наблюдателя; исправлено: один монитор на прогон).

4. Блок Repository rules содержит HTML-комментарии разметки инструкций (`<!-- swissknifeman:instructions… -->`, `<!-- semantic:… -->`). Мусор в промпте роли; чинить при сборке блока (срезать комментарии). Не обязательный блокер — в очередь на правку механизма между пунктами.
