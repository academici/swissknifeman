The package is built at the repository root under `src/skm/`. Some of the 14 modules
are still declarations; a file's presence does not prove its scenario works.

(module boundaries, registration points, fast checks) and the generated
[source index](reference/source-index.md) (every package, its entrypoints and the tests that import it).

## Sources and precedence

These English pages are the living architecture. The product lives at the repository
root. Declarations are separate from behavior, and generated DTOs are not handwritten.
Executor validation is separate from review; there is no per-leaf commit requirement.
Product checks, reviews, leases and permissions remain mandatory wherever their
contracts require them.

[Layers and modules](architecture/layers-and-modules.md) define canonical names and
precedence: module code defines meaning, migrations define database shape, and the
[configuration reference](reference/config.md) defines settings. The
[codebase map](architecture/CODEBASE-MAP.md) and [contract inventory](architecture/contracts.md)
name files and contracts; a file's presence does not prove the scenario works.
Follow the owning module's code. Do not register unfinished handlers or handwrite
generated DTOs.

## Working manually

Read the selected leaf and its sources, preserve unrelated work, implement within
its write set, and record actual commands and results independently of review.
Manual work does not require JSON reports, an automatic review loop or a commit
after each leaf. Follow the owner's explicit reporting and commit instructions.
An owner-directed campaign is a separate operating mode from this manual loop.

Pages under `reference/` are generated by `tools/gen.py` (`make gen`); never edit them by hand.
