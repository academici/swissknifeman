# P0 — Thin contract and adaptive commands

## Phase Context

Фаза уменьшает always-on инструкции и сводит общий plan canon к одному комбинированному
контракту: строгий design frame плюс адаптивное исполнение. P0.1 принадлежит Harness, меняет
instruction sources и централизует новые run-report'ы в repository root по D13; P0.2
принадлежит Skiller и меняет только canonical skill/reference.
Task-команды и runtime остаются P1.1. Канонические источники меняются раньше generated
projections; новый runtime/control plane не создаётся.

**Scope Included:** Harness instruction canon и repository-root run-report resolution, Skiller
`plan-protocol`, их provider projections и непосредственно связанные документы/проверки.

**Scope Excluded:** редизайн всех Task-команд, новый supervisor, cursor/lease/manifest batching,
ослабление authority/security gates и исчерпывающая тестовая матрица.

> **Контракт фазы (contract-first).** Потребляет: brief, repository map, verified RAG и D1–D7/D12/D13 · Производит: короткий always-on canon, repository-root run evidence и единый adaptive skill contract · Границы: Harness и Skiller исполняются из собственных package cwd; Task commands/runtime переданы P1.1; generated outputs only through owners.
