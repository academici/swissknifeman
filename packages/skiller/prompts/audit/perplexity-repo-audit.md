# Perplexity: внешний аудит swissknifeman

Репозиторий: https://github.com/academici/swissknifeman

Это монорепо экосистемы academici: реестр AI-скиллов (`skiller`) для Claude Code,
Cursor и Fable, плюс пакеты окружения (`harness`) и хаба памяти/графа (`maind`).

## Направления аудита

### 1. Актуальность технологий
- Актуальные версии: Laravel, Spatie, Filament, Livewire, Pennant.
- Актуальные идентификаторы моделей Claude API (на дату аудита).
- Живы ли внешние ссылки в документации и скиллах.

### 2. Best practices
- Сравни подход к скиллам/субагентам с актуальными агентными фреймворками.
- Какие паттерны устарели за последний год.

### 3. Конкуренты
- Что похожего есть в открытом доступе (реестры скиллов/промтов для AI-агентов).
- Чего не хватает по сравнению с ними.

Формат: структурированный список находок с источниками и датами публикаций.
Для каждой технологии: ✅ актуально / ⚠️ изменилось / ❌ устарело + ссылка.
