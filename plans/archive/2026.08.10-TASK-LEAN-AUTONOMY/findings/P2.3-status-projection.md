# P2.3 — owner status projection

## Before

With terminal P2.1/P2.2 and not-started P2.3/P2.4, the generated owner view
showed both P2 and the whole plan as `⬜ Not started`. The same truth-table gap
was reproduced black-box in `PlanStatusTests`: a phase containing `🟢 Done` and
`⬜ Not started` children returned `⬜ Not started`.

## After

`task.plan_status._phase_status()` keeps the existing priority for `🔴 Blocked`,
all-`🟢`, and all-terminal `🟢`/`🟠`. A mix of terminal and not-started children,
like an explicit `🟡 In progress` child, now returns `🟡 In progress`. The
black-box regression asserts the result both for its phase row and plan Meta.

The current generated owner view shows P2 and the plan as `🟡 In progress` while
P2.3 is running and P2.4 remains not started.
