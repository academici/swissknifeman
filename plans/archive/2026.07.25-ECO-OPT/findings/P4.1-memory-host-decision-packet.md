# P4.1 — пакет принятых решений (компактная выжимка для P4.2/P4.3)

Один файл входа вместо сбора решений по D-логу. Полное обоснование и известные ограничения —
`root/adr/ADR-0001-cross-machine-memory.md`; здесь только сами ответы и их провенанс.

| # | Пункт | Принятое решение | D-запись |
|:--|:--|:--|:--|
| 1 | Хост | ТЕКУЩАЯ машина | D80 |
| 2 | Транспорт (ближайшая стадия) | LAN, bind на конкретный LAN-адрес; `tailscale serve` на loopback-бэкенд — на триггере (третья машина ИЛИ работа вне LAN) | D80 (уточняет D78/D28) |
| 3 | `AGENTMEMORY_SECRET` | включаем; на LAN-стадии — единственный предохранитель, ACL/grants Tailscale заменены firewall-правилом хоста «один порт из подсети LAN» | D29 + D80 |
| 4 | Носитель токена / HTTP-клиент | `secret_file` (0600), НЕ env; аддитивное расширение `core.http` заголовками, второй HTTP-клиент в `maind` запрещён | D29 |
| 5 | Офлайн-деградация | fail-soft БЕЗ локального кэша/outbox; при `memory.role=client` подъём локального демона запрещён КОДОМ | D27 |
| 6 | Миграция стора | обнулена — хост совпадает с текущей машиной, переносить нечего | D80 |
| 7 | Бэкап | app-level export по расписанию + проверка ВОССТАНОВЛЕНИЕМ; ретеншн 7–30 дней + 1–3 месячных точки | D30 |
| 8 | Upstream `mesh-sync` | известен, НЕ используем | D31 |

**Отвергнутые варианты (с причиной):** bind `0.0.0.0` + firewall — key expiry перестаёт быть
предохранителем (D28); bind на tailnet-IP 100.x — снят выбором транспорта A (D78); mesh-sync —
два писателя + LWW-перетирание против единственного писателя (D31); локальный кэш/outbox — нет
версионирования/идемпотентности записи (D27).

**Известные ограничения LAN-стадии (полный список — в ADR):** секрет — единственный предохранитель ·
нет автоотзыва по key expiry · ротация ручная · сегмент LAN шире tailnet · триггер `tailscale serve`
— проверяемое условие, не «когда понадобится».

**Что это значит для P4.2:** `packages/maind/config/memory/iii-config.yaml` — в Scope Included и
`Files` (bind на LAN-адрес, не `0.0.0.0`); `memory.role` (`standalone`|`host`|`client`) — новое поле
конфига; `core.http` — аддитивное расширение заголовками; `secret_file` — носитель токена.

**Что это значит для P4.3:** гейт приёмки 4 — «недоступность из-за пределов подсети LAN» (не
tailnet); миграции стора нет (пункт 6 обнулён).
