# Perplexity: external audit swissknifeman

Repository: https://github.com/academici/swissknifeman

This is an ecosystem monorepo academici: registry AI-skills (`skiller`) for Claude Code,
Cursor and Fable, plus environment packages (`harness`) and memory hub/column (`maind`).

## Audit Areas

### 1. Relevance of technology
- Current versions: Laravel, Spatie, Filament, Livewire, Pennant.
- Current model IDs Claude API (as of audit date).
- Are external links alive in documentation and skills?

### 2. Best practices
- Compare the approach to skills/subagents with current agent frameworks.
- Which patterns have become outdated over the past year.

### 3. Competitors
- What is similar in the public domain (skill registries/promtov for AI-agents).
- What is missing compared to them.

Format: structured list of findings with sources and publication dates.
For each technology: ✅ relevant / ⚠️ changed / ❌ deprecated + link.
