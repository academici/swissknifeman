## Known deviation

The literal validation command `python3 -m unittest discover -s tests -p 'test_*publication*.py'`
fails before test collection because it does not expose package `lib/` or repository `core/` on
`PYTHONPATH` (`ModuleNotFoundError: skiller`; adding only `lib` then yields `ModuleNotFoundError:
core`). The same import topology exists in `HEAD` before P0.2 and is procedural, not a regression
of this scope. `scripts/test.sh` owns the package bootstrap and passed; changing that bare command
or broad test bootstrap lies outside this item's declared files.

The pre-mutation and pre-final Task Contract calls both returned `allow`, but the current v2 state
generator projects only the terminal journal note and cannot emit the required dedicated
`write-site: pre_mutation: allow · pre_final: allow` Completion Notes line. This is a P1.1-owned
Task runtime/carrier limitation; the pre-final command output is the evidence for this attempt.
