# Provider capability contract

**Version:** v0.1.0-draft  
**Status:** draft; sealing owner-gated in P0.3

Контракт должен определить provider IDs, capability vocabulary, support levels,
provider-native extension metadata и машиночитаемый источник, из которого генерируются
README matrix, validation gates и adapter diagnostics.

До P0.3 этот файл фиксирует только назначение; его поля и compatibility rules не являются
исполняемым контрактом.
