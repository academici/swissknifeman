# P5 — Harness: permissions, hooks, MCP, native features и instruction projections

## Phase Context

P5 отделяет semantic harness profiles от нынешнего `configs/claude-code`-центра и
вводит frozen contract, который P6 может потреблять без знания внутренних модулей harness.
Common catalog хранит stable intent/capability/security requirements, а named Claude/Codex
adapters рендерят нативные settings, trust/approval/sandbox, hooks/context, MCP и agents.
Claude Code сохраняет текущие presets, hook behavior, agent-pack upgrade/lock semantics и
settings doctor через independent compatibility gates. Codex получает native artifacts
только для explicit trusted target; unsupported capability остаётся diagnostic, а не
эмулируется ложным parity. Full access никогда не выбирается default/fleet inheritance.
Завершение фазы — frozen harness contract, dual renderers и independent conformance/doctor
evidence; self-host apply остаётся P7, FOREMAN/fleet не меняются.
После RED design-аудита фаза также замораживает общий instruction contract и до P6/P7
реализует один explicit canon для root/package `CLAUDE.md`/`AGENTS.md` projections.

**Scope Included:** provider-harness contract; semantic profile/surface catalog; provider
render plans; safe/autonomous/full-access security intents; trust/approval/sandbox mapping;
Claude compatibility; Codex native config/hooks/context; MCP descriptors; agents/subagents;
agent packs; provenance/lock/check/repair; provider doctor; generated operator reference.
Common instruction catalog; root и package-level Claude/Codex projections; managed
common/provider-extension blocks; semantic parity, source/render hashes, drift/repair
и legacy Claude compatibility.

**Scope Excluded:** изменение P1 config precedence; P2 artifact kernel; task command/model
semantics P4; mAInd deploy/sync и analytics P6; live self-host apply/release P7; secrets
values; runtime provider SDK; universal hook-event emulation; массовый fleet rollout;
FOREMAN execution; редактирование root bootstrap `.agents/skills` или текущих
`CLAUDE.md`/`AGENTS.md` outputs как канона; live root/package apply до P7.

> **Контракт фазы (contract-first).** Потребляет: terminal P4.5, frozen v1.0.0 capability/config/artifact/migration/skill-publication/command-routing contracts, P2 artifact engine, P4 command projections и current root/package instruction inventory · Производит: frozen provider-harness + provider-instruction contracts, common profile/instruction catalogs, Claude-compatible/Codex-native harness и root/package instruction render plans, independent conformance handoff для P6/P7 · Границы: не хранит secrets, не применяет self-host/fleet config, не включает full access неявно, не меняет FOREMAN/bootstrap roots и не переносит проектирование instruction mechanism в P7.

**Entry gate:** P5.1 не начинается, пока P0.3/P0.4, P1.1–P1.4, P2.1–P2.4,
P3.1–P3.5 и P4.1–P4.5 не терминальны; шесть входных contracts не frozen v1.0.0;
P2/P4 conformance не доказывает renderer/invocation API. Draft placeholders, текущий
Codex bootstrap config и full-access authoring session не являются contract/release
evidence. RAG:— (repo-grounded: `research/09-p5-harness-provider-surfaces-design.md`,
D11/D12/D20/D24–D27)
