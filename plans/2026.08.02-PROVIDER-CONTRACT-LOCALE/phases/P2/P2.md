# P2 — Freeze locale and compact-English authoring contract

## Phase Context

This phase defines, but does not implement, the provider-neutral locale and authoring contract
consumed by P3–P7. It starts only after terminal P1 control-plane and P0 recovery outputs, so
locale preference remains canonical intent rather than adapter state. P2.1 also freezes the
exact vendored IANA registry bytes/provenance consumed by later runtime code. Locale independently
resolves `response`, `plan`, and `diagnostics`; its trace is observable but stores no
environment values. The v1 rendered locales are `en` and `ru`, with BCP 47 normalization and
deterministic English fallback. Compact English is the semantic source; Russian is a
key-addressed rendering overlay, never an alternate canonical tree. No existing skill, plugin,
comment, document, configuration, provider projection, or fleet file is bulk-rewritten here.

**Scope Included:** independent `response`/`plan`/`diagnostics` locale policy; BCP 47 boundary
normalization and deterministic fallback; pinned IANA registry bytes plus adjacent provenance;
compact-English semantic ownership; sparse Russian
overlay format; immutable-token, generated-owner, review, rollback and admission contracts;
normative fixtures, checkers and exact Owner freeze gates.

**Scope Excluded:** runtime/provider implementation; rewriting canonical content or generated
targets; project/user/fleet writes; automatic translation or author self-review; translating
IDs, paths, commands, schema keys, placeholders, parser literals or diagnostic/action codes;
deleting legacy RU inputs or local overrides.

> **Контракт фазы (contract-first).** Потребляет: terminal P0 recovery evidence and frozen `provider-recovery-gates-v1`; terminal P1 and frozen `provider-control-plane-v1`; locale RAG/repository findings and current authoring/generator ownership · Производит: frozen `locale-resolution-v1`, `english-authoring-overlay-v1` and `locale-authoring-review-v1`, normative matrices/checkers and P4/P7 admission criteria · Границы: no runtime/content/generated/provider/fleet mutation, no second semantic source and no translation of machine identities.
