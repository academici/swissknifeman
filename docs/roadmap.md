# Roadmap

Идеи развития узла mAInd. Не обещания — направление.

## Сделано в 0.2.0

- **Федерация графа** + derive из источников истины (composer/Brain/override/skills).
- **Namespaces** — изоляция связей графа **и** памяти (бакеты `ns:<имя>`).
- **graphify** как со-равный механизм связей (граф кода), деплой отдельным MCP-сервером.
- **Healthcheck** связи проекта с хабом + доставка «приоритета №1» (hook + блок в `CLAUDE.md`).
- **Единый провижининг** `maind sync` (mcp/graph/memory/health-*) с режимами install/update/auto.
- **Workspace trust**; **MCP** закалён + расширен до 11 tools (в т.ч. `graph_path`, `memory_links`).
- Запись `maind` в MCP-карты потребляющих проектов автоматически; синк скиллов из swissknifeman.

## Память
- Семантический recall с ранжированием и суммаризацией (через `ANTHROPIC_API_KEY`).
- Авто-связывание новых фактов в граф (`memory` node + `belongs_to` к проекту).
- `export` поверх стабильного delete-контракта демона.

## Граф
- Полноценный адаптер `networkx` (алгоритмы центральности, сообщества).
- Склейка код-графа graphify с топологией maind (единый обзор «код ↔ зависимости»).
- `graph path --from --to` в CLI (сейчас — только MCP-tool); экспорт подграфа в HTML/SVG.

## Агенты
- Heartbeat-loop в SDK-обёртке (фоновое обновление `last_seen`).
- Изолированные scope памяти/графа на агента из коробки.
- Интеграция с `brain` AGENTS.md (автозагрузка дескрипторов).

## Мульти-хаб (федерация узлов)
- `node.role: secondary | mirror` — несколько хабов с синком графа/памяти.
- Экспорт совместимого подмножества обратно в brain (`projects export`).
