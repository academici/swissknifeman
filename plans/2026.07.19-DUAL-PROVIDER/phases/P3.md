# P3 — Dual skills publication и marketplaces

## Phase Context

P3 переводит skiller registry/publication/connect/vendor/update на один semantic
publication catalog и два provider-native adapter'а. Canonical skill content остаётся
в `packages/skiller/skills/`; Claude marketplace и существующие plugin names/settings
сохраняются byte-compatible, Codex получает `.codex-plugin/plugin.json`, repo marketplace
и управляемые `.agents/skills`/bundle outputs по собственному contract. P3 использует
P2 render/lock/provenance kernel и P1 provider selection, но не меняет task command semantics.
Завершение фазы — deterministic publication/install/update pipeline и exhaustive parity
evidence в synthetic/self-host-safe targets без записи в FOREMAN или fleet projects.

**Scope Included:** owner-approved skill/publication contract; immutable semantic catalog;
Claude marketplace adapter с back-compat golden; Codex plugin/marketplace/curated-bundle
adapter; provider loop для connect/vendor/explicit install/update/doctor; managed thin-vs-copy
ownership rules; inventory parity, drift, idempotence и no-write conformance.

**Scope Excluded:** task command bodies/model routing/invocation mapping (P4); harness
permissions/hooks/MCP/agents (P5); mAInd fleet deployment (P6); root README/self-host release
gate (P7); редактирование bootstrap `.agents/skills` как канона; automatic user-global install
без explicit action; FOREMAN execution/editing; fleet rollout; provider SDK/runtime dependency;
project-local `.ai/guidelines` distribution и новый generic template framework.

> **Контракт фазы (contract-first).** Потребляет: terminal P2.4, frozen v1.0.0 capability/artifact/config/migration-gate contracts, P1 provider resolver и P2 artifact/render/lock/catalog API + conformance evidence · Производит: frozen provider-skill-publication contract, byte-compatible Claude adapter, native Codex plugin/marketplace adapter, provider-aware connect/vendor/install/update/doctor и exhaustive parity evidence для P4/P7 · Границы: не переписывает task semantics, harness/mAInd surfaces, bootstrap root artifacts, FOREMAN или fleet targets.

**Entry gate:** P3.1 не начинается, пока P0.3/P0.4, P1.1–P1.4 и P2.1–P2.4 не
терминальны, четыре входных contracts не frozen v1.0.0, а P2 conformance не доказывает
deterministic plan/apply/repair. Draft placeholders и текущая untracked `.agents/skills`
не являются API/release evidence. RAG:— (repo-grounded: `phases/P2.md`,
`research/07-p3-dual-skill-publication-design.md`, D12/D16–D18/D20–D23)
