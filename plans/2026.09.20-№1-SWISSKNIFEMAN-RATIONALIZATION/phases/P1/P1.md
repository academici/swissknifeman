# P1 — Перепроверка оснований и измерительный baseline

## Phase Context

P1 превращает входной Perplexity-аудит и локальные наблюдения в проверенный
baseline. Детализация обязана повторить Perplexity и обычный web search, открыть
первичные источники для несущих выводов, сверить repository claims с кодом и
заморозить малый corpus, метрики и stop rules. Продуктовые изменения в P1 запрещены.

**Scope Included:** внешняя перепроверка; repository baseline; corpus, метрики, пороги и stop rules; проверка достоверности CI/run-report evidence.
**Scope Excluded:** изменение runtime, skills, provider mappings, hooks, docs и деревьев consumer projects.

> **Контракт фазы (contract-first).** Потребляет: owner brief, audit, design baseline · Производит: sealed baseline и measurement contract для P2–P5 · Границы: без product implementation.

> **Phase Assurance | v1.**
> Impact: internal-integration
> Integration Seams: `external-verification` · `repository-baseline` · `measurement-contract`
> Live or Irreversible: no
> Audit Intent: direct-close-eligible
> Rationale: P1 меняет только plan-owned evidence; item validation и phase gates должны доказать provenance, повторяемость и готовность baseline до закрытия.
