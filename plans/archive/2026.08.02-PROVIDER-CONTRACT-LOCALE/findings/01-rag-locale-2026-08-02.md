# RAG — Locale resolution and content fallback

**Date:** 2026-08-02

**Query:** configurable locale inheritance for developer tools and CLIs: default,
project/session/command overrides, BCP 47, fallback and avoiding duplicated translations.

## Extract

- Use BCP 47 identifiers externally and canonicalize input at the boundary.
- Separate preference resolution from content fallback. Precedence: command/session →
  environment → project → user → OS → built-in default.
- Keep one complete default-language resource set and sparse locale overlays; do not
  fork whole trees for regional differences.
- Log requested locale, resolved locale and fallback path for reproducible diagnostics.
