## Frozen mapping

`artifacts/P7.1/replay-admission-v1.json` is the sole admission denominator. Capability IDs reuse
the existing P4.3 row IDs; no second capability namespace is introduced. Each capability has one
positive implicit-trigger workflow, one negative implicit near-miss and one explicit boundary
workflow. The variants are exactly `no-skill`, `minimum-core` and `provider-tuned` for Claude Code
and Codex, producing 54 base runs. `provider-tuned` means the provider-native bootstrap projection
plus the same canonical body; identical projection bytes do not imply identical outcomes. RAG:—
(repo-grounded: D57, D58, `root/contracts/skill-core-v1.md`,
`root/contracts/provider-skill-adapter-v1.md`, and `root/contracts/skill-evidence-v1.md`).

Normative behavior beyond the minimum core is partitioned into named ablation units. Graders use
structured required/forbidden assertions per workflow, never one aggregate score. Green requires
the exact matrix, no negative false activation, no provider masking, no worse-than-baseline row and
at least one strict positive/boundary assertion improvement per provider/capability. A non-core unit
is retained only when isolated ablation reproduces its declared regression signal.

## Execution and safety boundary

The carrier freezes semantics, not provider CLI flags. The P7.1 runner resolves current native
invocation through the provider adapter, records provider/model/version/tool identity, and treats
unavailable execution as a release blocker. Replays are repository/fleet read-only. Evidence keeps
only assertions, bounded trace summaries and redacted references; raw hidden reasoning, roots,
secrets, settings values and provider payloads remain forbidden.

## DoR verdict

The P7.1 ambiguity is closed without broadening scope: exact selection, mapping, workflow family,
grader assertions, ablation denominator, provider non-masking and privacy/mutation gates are
machine-readable. P2/P4/P5/P6 contracts remain unchanged; P7.1 resumes at its existing
`implementation/high`, `manual`, `Review none` route.
