# P5 — Generated Asset Protection (фаза E)

## Phase Context

Защищаем generated-ассеты agent-packs от молчаливых правок. Сейчас provenance-маркировки в
сгенерированных файлах НЕТ (0 хедеров); lock уже хранит base_sha256/answers и прецедент
user_owned (`review-gate.env.ini`); upgrade умеет categorize (conflict→.pack-new). Решения:
provenance-header детерминированный, БЕЗ timestamp, хеш считается ВМЕСТЕ с header (D10) —
вместо Generated-at поле Pack-version; матрица `_decide`/`categorize_file_change` НЕ меняется.
Формат: `.md` — HTML-comment ПОСЛЕ frontmatter (swissknifeman:generated / Generated-by / Pack /
Template / Edit-policy / Extension-points / Upgrade-команда); `.js/.sh/.ini` — построчный после
shebang; kind:merge — без header; user_owned — `Edit-policy: user-owned`. Расширение — base+overlay
(D11): пак объявляет user_owned rules-оверлей, агент-шаблоны читают его ПОВЕРХ, ноль новой
механики. Mutation-телеметрия: слой 1 обязательный — lock_drift() + doctor --drift + самодостаточный
pack_drift() в maind analyze (~25 строк, maind не импортирует harness) → ATTENTION; слой 2
опциональный — PreToolUse-хук pack-guard (off|warn|strict, по умолчанию НЕ ставится).
Header меняет байты → patch-bump ВСЕХ паков; upgrade даст safe-apply чистым и conflict реально
правленным (желаемое: дрейф всплывает). Lock schema=1, только аддитивное поле user_owned.
